## 怎样使用

1. 打开对应资料的 README，查看环境、数据来源和复现范围。
2. 下载独立 ZIP 并解压；按该篇要求创建 Python 虚拟环境、安装依赖、运行入口。各篇 Python 版本和依赖不同，详情以本篇说明为准。
3. 图表可直接查看。交互 HTML 需下载到本地打开，并保留同目录资源；GitHub 文件页不执行这些页面。
