# ETF跌下去以后，多久才能涨回来？用Python看回撤与修复时间

版本：v1.0.1｜更新：2026-10-05｜行情截止：2026-09-30

这套资料使用16只宽基及行业ETF代表样本的近一年市场收盘价，提供最大回撤、下跌时长、修复时长与未修复观察时长，包含5组PNG/SVG、原始响应、16份日度CSV、事件表及可复现源码。配图品牌为“可以叫我才哥”。案例图以编号圆点标记高点、低点与修复或观察截止日，日期和数值通过引导线对应节点；标注位置根据实际文字框检查，避开价格线和其他文字。

## 数据与口径

窗口为2025-09-30至2026-09-30，每只ETF242个价格观测、241个相邻交易日间隔。高点从窗口起点建立，属于本窗口回撤。

行情由腾讯证券公开日线接口取得，统一请求前复权。13只返回qfqday；512880、515790、159819返回day，已通过天天基金历史分红拆分表核对暂无记录。核对网页原始响应以TXT保存，采集脚本可直接读取。

采集脚本尝试东方财富fqt=1作第二来源，本次完整采集时未取得有效响应。实际核对范围和状态保存在`数据/采集元数据.json`。

时间按交易日位置差计算：高点→低点为下跌时长，低点→首次收盘达到或超过原高点为修复时长。未修复的日期和时长保留空值，另记低点后已观察时长。相同高点取下跌前最后一次，相同最低价取第一次。

## 环境与运行

Python 3.10+。绘图使用Windows微软雅黑`C:\Windows\Fonts\msyh.ttc`；其他系统需在绘图脚本中设置可用中文字体。

```powershell
python -m pip install -r requirements.txt
python 分析与绘图.py
```

采集程序会优先使用固定窗口的已有原始响应。需要重新请求时，可在另外的临时目录复制采集源码并执行`python 采集数据.py`，获得新响应后核对再替换当前数据。固定窗口改变时，应同步复核统计结果和说明。

## 文件

- `采集数据.py`：行情采集、超时及有限重试、字段核对、分红拆分核对及原始响应保存。
- `回撤计算.py`：最大回撤、第一次修复及互不重叠事件识别。
- `分析与绘图.py`：数据明细、事件筛选、统计、绘图与独立复算。
- `数据/ETF行情.json`：16只ETF当前价格快照。
- `数据/*_回撤日度.csv`：逐日收盘价、滚动高点和回撤。
- `数据/最大回撤与修复.csv`：16只ETF最大回撤及时间记录。
- `数据/全部回撤事件.csv`、`数据/回撤超过5%的事件.csv`：事件记录。
- `图表/`：最大回撤总览、已修复案例、未修复案例、跌幅与所需涨幅、分状态事件散点，分别提供PNG与SVG。
- `分析结果.json`、`验收结果.json`：精确结果、计算与来源核对记录。

## 本例结果

16只ETF各自的窗口最大回撤均截至观察日尚未修复。窗口内全部回撤事件114次，其中跌幅至少5%的52次：36次已修复、16次尚未修复。

仅36次已修复事件的修复时长中位数17日、均值18日、范围2—42日。未修复事件仍保留，统计时需区分完成时长和观察时长；这些描述不能用作未来修复时间预测。

全部数据和图表按当前窗口计算。回到该次高点与个人持仓回本是不同口径，个人现金流和费用需另行考虑。
