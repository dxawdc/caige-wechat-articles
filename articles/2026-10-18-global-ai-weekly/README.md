# 全球AI周报10.18：芯片股一周跌24%，美欧出手管AI

更新日期：2026-10-18。版本：v1.0.0。

「全球AI周报」10.18期（2026年10月12日—18日）的配套资料：10只全球芯片龙头股和半导体ETF的本周行情快照，取数与绘图脚本，文中的一周时间线、芯片股本周涨跌幅两张图，以及横版、方版封面和可编辑模板。

## 资料内容

- `采集数据.py`：从 Yahoo Finance 获取 SK海力士、三星电子、爱德万测试、软银集团、AMD、博通、台积电ADR、阿斯麦、英伟达和 SOXX 的日线收盘价，计算本周累计涨跌幅、10月15日单日涨跌幅、截至周五的连跌天数和距10月高点回撤，输出到 `数据/`。
- `数据/芯片股日线收盘价.csv`：2026-09-15至2026-10-16的日线收盘价快照。
- `数据/芯片股本周涨跌幅.csv`：本周统计结果，文中图6和芯片股卡片的数字均来自这张表。
- `绘图.py`：生成 `配图/图1_一周时间线.png`（本周12件大事按日期与主线排列）和 `配图/图3_芯片股本周涨跌幅.png`。
- `生成封面.py`：用 `配图/封面底图.png` 合成横版（1800×766）、方版（1200×1200）封面与缩略图，同时生成 `配图/封面_横版模板.svg`、`配图/封面_方版模板.svg` 两个文字可编辑的矢量模板。每周修改脚本里的 `COPY` 文案即可复用同一版式。

## 如何运行

Python 3.10及以上：

```powershell
python -m pip install -r requirements.txt
python 绘图.py
python 生成封面.py
```

`绘图.py` 直接读取 `数据/` 中的快照。要换成其他周，修改 `采集数据.py` 中的 `START`、`END`、`WEEK_START`、`WEEK_END` 后运行 `python 采集数据.py`，再运行 `python 绘图.py`；时间线事件在 `绘图.py` 的 `fig_timeline()` 中手工维护。Windows默认使用微软雅黑。

行情接口示例（SK海力士日线）：

https://query1.finance.yahoo.com/v8/finance/chart/000660.KS?interval=1d&range=1mo

## 口径说明

- 本周累计涨跌幅 = 10月16日收盘 / 上周最后一个交易日收盘 - 1。韩国10月9日（韩文日）休市，韩股以10月8日收盘为基准；日本10月12日（体育日）休市，本周4个交易日。
- 连跌天数按日线收盘价逐日比较，统计截至10月16日（周五）。
- 新闻事件的日期按事件公开或报道日期记录，来源见文末信息来源。
