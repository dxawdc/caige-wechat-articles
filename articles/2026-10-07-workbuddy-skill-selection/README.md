# WorkBuddy 技能选型配套资料

按办公文件、写作、配图、资料整理等工作需要，整理16个技能的来源索引，以及7张场景选型图。

## 提供的物料

- 技能来源索引：作者、原始仓库、说明文件核对日期、SHA-256及WorkBuddy能力/市场核对状态。
- 对话安装清单：16项可复制的安装与验证要求，把名称和来源一起发给WorkBuddy执行。
- 7张选型图：PNG阅读版和可编辑SVG。
- 横版与方版AI概念封面、独立可编辑封面模板及设计说明。
- 生成选型图.py：同时生成PNG与SVG的源码。
- 最新下载包.zip：一份可直接下载使用的完整配套包。

## 生成图片

使用Python 3与Pillow。Windows默认字体路径为C:/Windows/Fonts/msyh.ttc，其他环境通过--font指定已安装的中文字体。

```shell
python -m pip install Pillow
python 生成选型图.py --font "C:/Windows/Fonts/msyh.ttc"
```

PNG适合阅读与分享；SVG中的文字和图形可以分别编辑。AI封面由内置imagegen生成，独立模板由脚本绘制，设计说明记录提示词。

## 来源与使用

功能介绍以各作者的公开说明为依据，完整入口见技能来源索引.md。WorkBuddy官方已介绍办公文档四件套；其余社区项目的内置市场收录尚未逐项确认。先检查已有能力，再让WorkBuddy查找或按指定来源安装，并验证实际调用与示例结果。需要的工具、服务和账号配置由它逐项检查。
