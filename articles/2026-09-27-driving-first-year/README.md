# 拿驾照满一年：Plotly 驾驶数据分析配套资料

对应公众号文章《拿驾照满一年，我用 Plotly 复盘了 566 条市内开车记录》。本目录提供绘图源码、180 条虚构演示行程、文中 10 张图、封面和匿名统计摘要。图 02 是累计里程动态 GIF。

## 使用方法

使用 Python 3.10+，安装依赖后运行：

```powershell
python -m pip install -r requirements.txt
python 生成演示数据.py
python 绘制图表.py --csv 数据/演示行程.csv --output 演示输出
```

生成结果位于 `演示输出/`，包含 PNG、GIF、Plotly 交互 HTML 和统计摘要。可用浏览器打开交互 HTML，悬停查看数值或播放累计里程动画。`生成演示数据.py` 使用固定随机种子，重新运行可得到相同的 180 条练习记录。

## 数据与图表

演示行程的日期、时段、里程、时长、速度和通用起终点名称由程序独立生成，用于复现绘图方法。文中图表展示的是高德“足迹人生”页面卡片的聚合结果，统计单位为卡片。年度日历范围为 2025-10-01 至 2026-09-27；分析窗口为 2025-09-27 至 2026-09-26。`数据/匿名统计摘要.json` 记录文章使用的汇总口径。演示数据运行后产生的数字是练习结果，与文章数字分别阅读。

图表使用低饱和绿、暖杏色和奶油白：深松绿 `#30483E`、鼠尾草绿 `#719D8B`、浅薄荷绿 `#A9C9B9`、暖杏色 `#CC9172`、奶油白 `#FFF9F1`。脚本中可以直接调整这些色值。

## 文件说明

| 路径 | 内容 |
| --- | --- |

| `数据/演示行程.csv` | 180 条虚构卡片 |
