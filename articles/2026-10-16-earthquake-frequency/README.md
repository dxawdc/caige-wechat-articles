# 地震真的变多了吗：50年地震目录数据观察

更新日期：2026-10-16。版本：v1.2.0。

用USGS地震目录，观察最近30天全球地震、1950年以来全球大地震的年度变化、地震与板块边界的关系、中国各省级区划的地震分布，以及2026年中国5级以上地震与历年的对比，并以2025年堪察加8.8级地震为例展示余震衰减。

## 资料内容

- `采集数据.py`：从USGS FDSN Event API分年下载地震目录，生成 `数据/` 下的5个CSV。
- `数据/全球6级以上_1950起.csv`、`数据/全球5级以上_2016起.csv`、`数据/全球4.5级以上_最近30天.csv`、`数据/中国周边4.5级以上_1976起.csv`、`数据/堪察加序列_2025.csv`：截至2026-10-16（UTC）的数据快照。
- `数据/底图/`：省级区划（阿里云DataV）、板块边界（Bird 2003 PB2002）、陆地轮廓与国家区域（Natural Earth）。
- `绘图.py`：省份归属、统计与绘图，生成 `图表/` 下10张PNG、1张GIF动图和 `分析结果.json`。
- `分析结果.json`：文中引用的全部统计数字。
- `生成封面.py` 与 `配图/封面_*`：无文字“地球火环”插画原图，以及裁好的横版（1800×766）、方版（1200×1200）封面。

## 如何重绘

Python 3.10及以上：

```powershell
python -m pip install -r requirements.txt
python 绘图.py
```

`绘图.py` 直接读取 `数据/` 中的快照。要更新到最新日期，先修改 `采集数据.py` 中的 `CUTOFF` 和各任务的起始日期，再依次运行 `python 采集数据.py` 和 `python 绘图.py`（`绘图.py` 中的 `UTC_END` 同步修改）。Windows默认使用微软雅黑。

数据接口示例（2026年以来全球6级以上地震）：

https://earthquake.usgs.gov/fdsnws/event/1/query?format=csv&starttime=2026-01-01&minmagnitude=6

## 口径说明

- 震级均为USGS震级；文中注明“台网测定”的数值来自中国地震台网正式测定，两者可能不同。
- 中国统计：震中位于省级区划内计入该省；不在其他国家陆地上、且距较大陆地约100千米（0.9个纬度当量）以内的海上地震计为该省近海。
- 板块边界附近：震中与PB2002板块边界的球面距离在200千米以内。
- 地图仅绘制陆地轮廓与板块边界，不表示行政边界。
