## 运行

本次验证环境：Python 3.12.14。进入本目录后运行：

```powershell
python -m pip install -r requirements_v1.0.0.txt
python "案例与绘图_v1.0.0.py"
```

程序会重建本目录的教学数据、结果和两张结果图；不要把真实业务文件放入这些输出目录。封面为配套静态物料。中文字体默认优先 Microsoft YaHei，在其他系统可安装 Noto Sans CJK SC 或修改绘图工具中的字体列表。

## 文件说明

- 案例与绘图_v1.0.0.py：模拟输入、计算、断言和绘图。
- 绘图工具_v1.0.0.py：公共静态绘图样式，运行时需要保留在同目录。
- 数据：可检查的 CSV 原始或派生数据。
- 图片：本文封面与两张实际结果图。
- 结果：案例关键数值与验收状态。
- SQL 文件（如有）：与实际执行一致的完整查询，使用 SQLite 方言。

所有业务数值均为教学模拟数据；观察窗口、分母和具体处理规则以脚本为准。通过断言不代表已覆盖真实业务的所有边界。
