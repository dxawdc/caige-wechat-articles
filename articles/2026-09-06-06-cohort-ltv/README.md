## 本包解决什么问题

注册与支付 → 用户日龄 → 成熟累计窗口 → 价值口径和批次加权。

预期结果：**A 的 7 日=7 元、14 日=10.2 元；B 的 7 日=9.1 元、14 日未到期。独立成本情景为 7/6.5/3.9 元，不是实际平台费率。**

## 独立下载与运行

[仅下载本篇 ZIP](https://raw.githubusercontent.com/dxawdc/caige-wechat-articles/main/downloads/06-cohort-ltv_v1.1.1.zip)。解压后进入 `06-cohort-ltv_v1.1.1` 目录，使用 Python 3.12：

```powershell
python -m pip install -r requirements_v1.1.1.txt
python "运行_06_游戏LTV_v1.1.1.py"
```

专属入口先复制本包材料到 `运行结果/06-cohort-ltv/`，再运行本篇基础和进阶脚本。包内原始样例与清单保持不变；重复运行会更新该输出目录的教学结果。请勿将真实业务文件放入这个输出目录。

基础脚本：`案例与绘图_v1.0.0.py`。进阶脚本：`进阶案例_v1.1.0.py`。绘图工具及部分依赖跨篇复用，核心案例、输入数据、结果和本包入口属于本篇。
