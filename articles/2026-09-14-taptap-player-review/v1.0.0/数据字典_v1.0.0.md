# 数据字典

## 本地清洗表（公开包不含逐条评论）

粒度为一个review_id，本次保留每个ID在采集过程中第一次遇到的版本。user_key只用于本地检查不同账号数，不作为真实自然人唯一证明。

| 字段 | 类型/口径 |
|---|---|
| review_id | 顶层评价ID，字符串；楼中楼回复不计入 |
| user_key | 用户公开ID的单向摘要，只保留本地 |
| created_time | 北京时间，评价创建时间 |
| edited_time | 北京时间，接口返回修改时间，缺失时取创建时间 |
| version_time | 两个时间的较大者，当前可见版本的时间归属 |
| version_day | 版本时间的自然日，YYYY-MM-DD |
| is_edited | 页面返回修改标记 |
| cross_launch_edit | 创建于开服前而版本时间在开服后 |
| score | 1—5星 |
| positive/negative | 4—5星/1—2星的布尔指标，不是文本情绪标签 |
| stage/stage_label | 平台原始状态数值及文字，不将缺失映射为未玩过 |
| played_seconds/played_hours | 评价时展示时长，秒/小时；缺失保留 |
| total_played_seconds | 当前总时长，不能回填评价时长 |
| hidden_spent | 隐藏时长标记；默认False不表示已获得时长 |
| play_group | [0,1)、[1,5)、[5,20)、[20,+∞)小时及缺失 |
| has_badge | 是否展示徽章，不是账号等级 |
| account_level | 本次不可用；徽章level从未填入此列 |
| ups | 评价点赞数，仅保留研究核查，不做评分权重 |
| text/text_length | 本地清洗原文及字符数 |
| period | 按版本时间划分的首发阶段 |
| 十个主题列 | 正则主题提及布尔值；多标签，不是方面情绪 |

## 公开汇总数据

`collection_summary_v1.0.0.json`：采集起止（UTC）、页数、是否抵达列表末尾、去重数、状态与时长字段覆盖、时间跨度。这里的UTC起止换算北京时需加8小时。

`analysis_v1.0.0.json`：overall、rating_counts、stages、hours、daily、periods、matched、themes、theme_periods、keywords、nmf及sensitivity。n为该组有效1—5星评价条数，high/middle/low分别为高/中/低星数，rate为相应条数除n，ci为二项Wilson区间。

主题mention_rate的分母为全样本；theme_periods中的rate分母为该阶段所有评价。NMF的n为最大权重归组的有效去重文本数，keywords权重为共同词表下的阶段平均TF-IDF。

时间边界：2026-09-10 07:00:00+08:00。所有窗口左闭右开，96小时对比与7天前窗主题图使用不同窗口，文章和图中分别标注。日图的9月10日包含开服前7小时，不能替代精确小时分窗。
