# GDN（游条）项目介绍：配图资料

| 文件 | 对应内容 |
| --- | --- |
| `images/小程序昨日简报.png` | 微信开发者工具模拟器中的昨日简报、总览和推荐阅读 |
| `images/小程序重点事件.png` | 微信开发者工具模拟器中的行业事件 |

## 查看方式

直接打开 `images/` 下的 PNG 文件即可；无需安装依赖。前台网页地址：https://youtiao.fun/ 。

本资料包只包含文章配图，不包含 GDN 后台凭据、数据库或项目源码。正文尚未公开时，本目录也不代替公众号文章全文。
