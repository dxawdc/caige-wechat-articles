# A股指数波段回测：32个指数 × 24条规则

更新日期：2026-10-17。版本：v1.0.0。

用7个宽基指数和25个中证主题指数，回测单均线、双均线、突破、RSI超跌低吸4类共24条波段规则，与买入持有对比；并做前后段检验、逐年超额和交易成本敏感性分析。

## 资料内容

- `数据/指数日线.json`：7个宽基指数日线（腾讯行情，2012年起），含开盘价与收盘价。
- `数据/主题指数日线.json`：25个中证主题指数日收盘（中证指数有限公司官网，2014年12月起）。
- `采集数据.py`、`采集主题.py`：采集上述两份数据。
- `回测.py`：规则定义、信号生成与回测函数，运行后输出宽基的 `回测结果.csv`、`逐年收益.csv`。
- `主题回测.py`：同一套规则跑25个主题，输出 `主题回测结果.csv`、`主题逐年收益.csv`。
- `绘图.py`、`绘图_主题.py`：生成全部图表，以及 `分析结果.json`、`主题分析结果.json`。
- `图表/`：
  - `图1_持有10年.png`：宽基买入持有的累计涨跌；
  - `图2_规则指数热力图.png`、`图3_净值对比.png`：24条规则×7个宽基的超额，及4个宽基的净值对比；
  - `图4_持有收益与波段胜率.png`：32个指数的持有年化与规则跑赢比例；
  - `图5_主题规则类别热力图.png`、`图6_主题净值对比.png`：25个主题×4类规则的超额中位数，及4个主题的净值对比；
  - `图7_逐年超额_均线.png`、`图7_逐年超额_低吸.png`：两类代表规则的逐年超额；
  - `图8_前后段检验.png`：2016—2020年与2021年以来的规则表现对比；
  - `图9_成本敏感性.png`：不同单边成本下的超额。
- `生成封面.py` 与 `配图/封面_*`：横版封面及可编辑模板。

## 如何复现

Python 3.10及以上：

```powershell
python -m pip install -r requirements.txt
python 回测.py
python 主题回测.py
python 绘图.py
python 绘图_主题.py
```

脚本读取 `数据/` 下2026-10-16的数据快照。更新数据：先运行 `python 采集数据.py` 和 `python 采集主题.py`（需修改脚本中的截止日），再依次运行上面的命令。

## 规则与口径

- 单均线：收盘价高于N日均线时持有，N=10/20/30/60/90/120/250。
- 双均线：短期均线高于长期均线时持有，(5,20)(10,30)(10,60)(20,60)(20,120)(30,120)(60,250)。
- 突破：收盘价创前N日新高买入，跌破前M日新低卖出，(20,10)(55,20)(60,30)(120,60)(250,120)。
- RSI低吸：14日RSI低于a买入、高于b卖出，(20,50)(25,55)(30,60)(30,70)(35,65)。
- 当日收盘产生信号，下一交易日收盘成交；单边成本0.05%，空仓不计利息；价格指数不含分红。
- 评估区间2016年初至2026-10-16；科创50自2021年起，5G通信、卫星产业自2017年起，留出一年计算长均线。
- 前后段检验：2016—2020年为前段，2021年以来为后段。
