# 国庆渐变头像：从20行循环到一句话AI

版本：v1.0.0 ｜ 更新时间：2026-09-29 ｜ 配套公众号文章《5年前写的国庆头像教程，我用2026年的技术重做了一遍》

五星红旗半透明渐变头像的多种实现：Python 三方案（putalpha 渐变、numpy 像素融合、blend 半透明）、单文件网页版 Canvas 工具、AI 抠图合成示例，以及逐像素旧写法与向量化新写法的性能对照。

## 目录结构

```
flag-avatar_v1.0.0/
├── scripts/                     全部代码与工具
│   ├── 绘图_00_测试素材.py       生成演示国旗（30×20 网格规范比例）与测试头像
│   ├── 绘图_01_技术方案.py       方案一 putalpha / 方案二 numpy / 方案三 blend
│   ├── 绘图_02_性能对比.py       逐像素循环 vs numpy 向量化实测
│   ├── 绘图_03_对比拼图.py       四宫格效果对比图
│   ├── 绘图_04_真实头像效果.py    对任意头像生成渐变与半透明两款效果
│   ├── 国庆头像生成器.html       单文件网页版工具（渐变/半透明，纯本地处理）
│   └── rembg抠图合成示例.py      AI 抠图（U2Net）+ 国旗前景合成
├── images/                      文章配图：效果大图、对比图、网页工具界面
└── 物料清单_v1.0.0.json         文件清单与 SHA-256
```

## 使用方法

```bash
python -m pip install pillow numpy

python scripts/绘图_00_测试素材.py    # 生成演示素材（国旗 + 测试头像）
python scripts/绘图_01_技术方案.py    # 三种方案效果，输出 images/
python scripts/绘图_02_性能对比.py    # 复现性能数据

# 用自己的头像生成效果（可选）
python scripts/绘图_04_真实头像效果.py 你的头像.jpg
```

网页工具无需安装任何东西，浏览器直接打开 `scripts/国庆头像生成器.html` 即可：上传头像、选模式、点保存，图片全程本地处理。文章中的性能数据为本机实测（Windows 11 / Python 3.13 / Pillow 12 / numpy 2.5）：900×900 图片 766.9ms → 1.5ms，2000×2000 图片 3834.5ms → 7.2ms。

## 数据与素材来源

- 国旗演示素材由 `绘图_00_测试素材.py` 按《国旗法》附件比例规范绘制（3:2 旗面、30×20 网格、五星定位与角尖指向），用于跑通流程；正式制作头像请使用标准国旗图片。
- AI 抠图示例基于开源 `rembg`（U2Net 分割模型），首次运行自动下载模型权重，全程本地推理。
- 效果演示使用的头像为作者本人的公众号卡通形象。

## 使用注意

- 国旗及其图案的使用请遵守《中华人民共和国国旗法》相关规定；本资料仅用于技术学习与演示。
- `绘图_04_真实头像效果.py` 与网页工具只在你自己的电脑上处理图片，不联网、不上传。
