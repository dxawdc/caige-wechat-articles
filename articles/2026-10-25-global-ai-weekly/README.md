# 全球AI周报10.25配套资料

更新日期：2026-10-25。版本：v1.0.1。

提供2026年10月19—25日全球AI周报的新闻来源索引、10只AI产业链观察样本行情、取数与绘图脚本、时间线、横版与方版封面及可编辑SVG模板。

## 内容与使用

- `数据/新闻来源.json`：原始出处、公开日期、核实要点与表述范围。
- `数据/芯片股日线收盘价.csv`：2026-09-15至2026-10-23未复权日线收盘价。
- `数据/芯片股本周涨跌幅.csv`：10月19—23日周涨跌幅、期末日期与交易日数。
- `采集数据.py`：从Yahoo Finance取数，保存原始响应与计算结果。
- `绘图.py`：从CSV复现时间线与涨跌幅图。
- `生成封面.py`：合成封面并生成文字与形状可独立编辑的SVG模板。
- `封面提示词.txt`：内置imagegen生成本期概念插画的提示词。
- `配图/`：时间线、行情图、封面底图、成品与可编辑模板。

Python 3.10及以上，安装依赖后可以直接读取快照绘图：

```powershell
python -m pip install -r requirements.txt
python 绘图.py
python 生成封面.py
```

重新取数运行 `python 采集数据.py`。其他周次可修改其中的 `START`、`END`、`WEEK_START`、`WEEK_END`，再调整绘图脚本中的时间线事件。Windows默认使用微软雅黑，其他系统可修改为本机中文字体。

## 数据口径

周涨跌幅 = 2026年10月23日收盘 / 2026年10月16日收盘 − 1。本期10只样本均有5个交易日，基准日和期末日在CSV中列明。使用原币种未复权收盘价，不含分红收益、汇率换算与交易费用。

固定样本覆盖SK海力士、三星电子、爱德万测试、软银集团、AMD、博通、台积电ADR、阿斯麦、英伟达与SOXX。软银是投资集团，SOXX是ETF；样本用于跨期观察，不代表全行业指数。本期为7跌、2涨、1平，软银−13.51%，SOXX−3.08%。

连续下跌天数按逐日收盘比较；距10月高点指已采集10月日收盘最高值至期末的变化。新闻截至北京时间2026年10月25日16:00，时间线使用原始来源记录的本周公开或更新日期。性能、任务成本与部署时长属于厂商或论文作者报告；来源索引区分已上线、计划开放和研究结果。

行情接口示例：

https://query1.finance.yahoo.com/v8/finance/chart/9984.T?interval=1d&range=1mo
