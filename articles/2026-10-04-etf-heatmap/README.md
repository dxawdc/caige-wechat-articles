# 用 Python 做一张 ETF 热力图：20 日涨跌、动量、波动和回撤一起看

版本：v1.0.0；资料整理：2026-10-06；行情快照：2026-09-30。

16 只宽基与行业 ETF，20 个交易日逐日涨跌和 11 项指标放在一张热力图上，按 20 日动量排序。收益观察窗口为 2026-09-02 至 2026-09-30，基准收盘日为 2026-09-01。

## 快速复现

Python 3.10+。在解压后的目录执行：

```bash
python -m pip install -r requirements.txt
python 绘图_叠加.py
```

绘图读取包内固定行情快照，生成高清 PNG、矢量 SVG、指标 CSV/JSON 和指标说明。Windows 推荐使用微软雅黑或黑体；其他系统请安装中文字体，并在绘图脚本的 `font.sans-serif` 中配置字体名。

## 指标与颜色

11 项指标包括 5/10/20 日动量、5 日加速度、20 日超额、MA20 乖离、RSI(14)、上涨占比、年化波动、最大回撤和 5/20 均量。20 日收益使用 21 个收盘价；超额收益以沪深300ETF（510300）为基准；年化波动使用样本标准差乘 √252；回撤按正幅度显示。公式见指标说明。

红色表示正收益，绿色表示负收益；蓝色表示强度或量能，金色表示波动与回撤。5/10/20 日动量共用色标，其余指标按列使用对应色标。数值、单位和色标共同用于解读图表。

## 数据来源与更新

数据来自腾讯证券第三方日线接口，采集地址模板：

`https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={market_code},day,,,120,qfq`

统一请求前复权 `qfq`，实际返回 `qfqday` 或 `day` 字段记录在采集验收中，计算使用接口返回的价格。跨分红、拆分日期使用时，需要核对复权口径；价格涨跌与包含现金分红再投资的总回报口径不同。

重新采集最新日线并绘图：

```bash
python 采集ETF行情.py
python 绘图_叠加.py
```

重新采集会更新行情快照与交易日窗口。16 只 ETF 全部采集成功且最近 21 个日期对齐后保存数据。

```bash
python 采集ETF行情.py --check
```

`--check` 比较线上行情和本地快照，并写出采集核验结果。线上行情随交易日更新，是否与固定快照一致以报告的 `all_snapshot_series_match` 为准。
