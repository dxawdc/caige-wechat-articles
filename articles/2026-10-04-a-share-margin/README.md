# 融资净买入与市场涨跌：把当日和次日分开看

提供融资数据采集、余额与每日净买入趋势、当日及下一交易日涨跌散点、分季度与强弱分组分析，以及7组高清PNG/SVG。图表署名“可以叫我才哥”。

## 数据范围与结果

信息截止2026年9月30日。沪市官方数据覆盖2025-09-30至2026-09-30，共242个交易日。深市9月30日查询返回空数据，沪深合计使用2025-09-30至2026-09-29的241个完整交易日，下一交易日收益最后观察到2026-09-30收盘。

沪深最新完整融资余额为2.571万亿元。净买入与沪深300当日涨跌的Pearson相关系数为+0.516，与下一交易日涨跌为−0.154。9月30日沪市融资余额12,965.21亿元、融资净买入−229.62亿元。

融资净买入按“买入额−偿还额”计算。融资汇总范围为沪市、深市股票和符合条件的基金；沪深300价格指数作为市场价格表现的参照。相关关系是本窗口的历史描述，预测能力需进一步验证。

## 环境与运行

Python 3.10+。Windows制图使用`C:\Windows\Fonts\msyh.ttc`微软雅黑；其他系统在`绘图与分析.py`中设置可用的中文字体路径和名称。

解压ZIP，在该资料目录执行，使用已保存的数据快照即可复现：

```powershell
python -m pip install -r requirements.txt
python 绘图与分析.py
```

如需重新查询公开数据，再运行`python 采集数据.py`，随后运行绘图脚本。当前截止日期固定为2026-09-30；调整观察窗口时应同步核对日期范围、样本和统计结果。第三方接口可能变化，采集脚本设置正常TLS校验、超时、有限重试与响应检查。

## 目录与输出

- `采集数据.py`：东方财富沪深融资汇总、腾讯证券沪深300日线、交易所核对响应。
- `绘图与分析.py`：日期合并、余额和净买入、当日与次日收益、分季度与分位分组、PNG/SVG输出及数值验证。
- `数据/`：原始响应、来源与采集时间、沪深合计和沪市单独日度明细。
- `图表/`：总览、沪深趋势、沪市趋势、当日散点、次日散点、并排对照、四组上涨占比，以及品牌配图。
- `分析结果.json`、`分析说明.md`：精确结果和读图说明。
- `验收结果.json`：唯一日期、有限数值、交易日对齐、官方数据核对和Pearson独立复算。
- `配图预览.html`：下载到本地后打开，逐张查看高清配图。
- `物料清单.json`：当前文件的SHA-256和字节数；ZIP与当前资料目录一致。

## 数据来源

融资余额、买入额及深市偿还额来自[东方财富融资融券数据](https://data.eastmoney.com/rzrq/)的`RPTA_WEB_RZRQ_LSSH`汇总报表。沪市偿还额采用[上交所融资融券汇总](https://www.sse.com.cn/market/othersdata/margin/sum/)历史日度数据，沪市余额和买入额也逐日核对。

深市余额和买入额以[深交所融资融券交易信息](https://www.szse.cn/disclosure/margin/margin/index.html)进行最新完整日期抽样核对。指数来自腾讯证券公开日线接口，使用沪深300价格指数`000300`。

金额原始单位为人民币元；余额曲线换算为万亿元，净买入换算为亿元，指数收益为百分数。下一交易日先在完整指数交易日序列中确定，再与融资日期合并。
