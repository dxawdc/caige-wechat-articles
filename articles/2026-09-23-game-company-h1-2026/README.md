# 2026年上市游戏公司半年报深度分析：配套资料

对应公众号文章《逐一筛查142条候选记录：2026游戏公司半年报，增长、员工和产品都在分化》的数据、分析脚本与10张高清图表。

本项目从A股、港股、美股、新三板和外部榜单建立候选池，再按上市主体、主营构成和报告可得性分层。正文财务统计使用24家A股主样本，跨市场数据用于观察量级；分析进一步覆盖归母与扣非利润、经营现金流、员工变化、费用结构、财报产品提及和重点公司产品生命周期。

## 核心口径

- 报告期：2026年1—6月，对比2025年同期。
- A股主样本：14家核心样本 + 10家重要样本，共24家。
- 候选池：142条记录是跨市场筛选与分层底稿，最终上市主体数量以市场、主体性质和分析层级字段为准。
- 营收口径：上市公司合并营业总收入，部分公司同时经营非游戏业务。
- 聚合同比：`2026H1合计值 / 2025H1合计值 - 1`。
- 利润质量：同时比较归母净利润、扣非归母净利润和经营活动现金流净额。
- 员工口径：2024、2025完整年报披露的年末人数，用于观察组织变化；半年报职工现金支出单独比较。
- 产品索引：程序筛出的428条记录包括同一产品的不同写法、IP名和重复提及；重点分析使用人工复核的24组产品。
- 游戏分部估算：按公司主营构成披露汇总，用于核对样本纯度。

## 复现方式

使用Python 3.10+，安装依赖：

```bash
pip install matplotlib numpy
```

在本目录运行：

```bash
python 分析/文章分析.py
```

脚本会复算A股24家主样本指标，更新`分析/文章关键指标.json`，并生成营收增量、营收排行、利润增量和费用结构4张图。其余6张深度分析图对应的数据底表和聚合结果也已列在上述目录中，便于检查和二次创作。
