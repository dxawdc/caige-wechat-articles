# 24家A股游戏公司2026年半年报分析：配套资料

对应公众号文章《24家A股游戏公司半年报：营收增长18%，为什么多数公司体感没那么好？》的可复现数据、分析脚本与4张图表。

本项目从“网络游戏”“电子竞技”“游戏Ⅱ/Ⅲ”等板块建立候选池，再按2026年半年报主营构成核对游戏业务相关性，形成14家核心样本与10家重要样本。分析重点比较样本公司的营业总收入、归母净利润、销售费用率和研发费用率，并用营收增量与利润绝对增量观察增长集中度。

## 目录结构

| 路径 | 内容 |
| --- | --- |

| `图表/` | 营收增量桥、营收排行、利润绝对增量、核心样本费用结构 |

## 核心口径

- 报告期：2026年1—6月，对比2025年同期。
- 主样本：A股14家核心样本 + 10家重要样本，共24家。
- 营收口径：上市公司合并营业总收入，部分公司同时经营非游戏业务。
- 聚合同比：`2026H1合计值 / 2025H1合计值 - 1`。
- 公司同比中位数：对24家公司各自披露的同比值取中位数。
- 利润变化：图表采用归母净利润绝对增量，便于处理上期利润接近零、扭亏或由盈转亏的公司。
- 游戏分部估算：按公司主营构成披露汇总；电魂网络、吉比特按纯游戏公司取营业总收入，用于核对样本纯度。

## 复现方式

使用Python 3.10+，安装依赖：

```bash
pip install matplotlib numpy
```

在本目录运行：

```bash
python 分析/文章分析.py
```

脚本会更新`分析/文章关键指标.json`，并在`图表/`生成4张PNG图片。
