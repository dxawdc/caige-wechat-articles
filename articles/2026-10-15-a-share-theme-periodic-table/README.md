# A股主题"元素周期表"：10年冠军轮动

更新日期：2026-10-15。版本：v1.0.0。

把25个中证主题指数2017年至今的年度涨跌排成"元素周期表"，并统计冠军次年排名、重点主题排名轨迹、10年累计涨跌和最近12个月的月度轮动。

## 资料内容

- `数据/主题指数日线.json`：25个中证主题指数日收盘（2016年至2026-10-15），含指数代码、全称与对应的东方财富主题。
- `采集数据.py`：从中证指数有限公司官网采集日收盘。
- `绘图.py`：生成全部图表、动图和 `分析结果.json`。
- `分析结果.json`：年度/月度涨跌、冠军与垫底、冠军次年排名、相邻年份排名相关系数、10年累计等统计。
- `图表/`：
  - `图1_逐年揭晓.gif`：周期表逐年揭晓动图；
  - `图2_年度周期表_红绿.png`、`图2_年度周期表_大类.png`：年度周期表两种配色；
  - `图3_冠军次年排名.png`、`图4_重点主题排名.png`、`图5_10年累计.png`；
  - `图6_近12个月月度周期表_红绿.png`、`图6_近12个月月度周期表_大类.png`：月度周期表两种配色。
- `生成封面.py` 与 `配图/封面_*`：横版封面及可编辑的横版、方版SVG模板。

## 如何重绘

Python 3.10及以上：

```powershell
python -m pip install -r requirements.txt
python 绘图.py
```

`绘图.py` 读取 `数据/主题指数日线.json` 的2026-10-15快照。更新到最新交易日：先运行 `python 采集数据.py`，再运行 `python 绘图.py`。Windows默认使用微软雅黑。

## 主题与口径

- 25个主题分为6个大类：科技（人工智能、5G通信、半导体、云计算、消费电子）、高端制造（机器人、智能汽车、军工、卫星产业）、新能源与电力（新能源、光伏、电池、核电、电网设备）、资源（油气、有色金属、黄金采掘、稀土）、金融（银行、证券）、消费医药（主要消费、白酒、生物科技、创新药、医疗器械）。
- 重点主题：白酒、银行、半导体、新能源、稀土、黄金采掘、5G通信、创新药、消费电子。
- 均为价格指数，不含分红。年度涨跌以上一年最后一个交易日收盘为基准，2026年为年初至今；月度同理。
- 红绿版色阶：年度±50%、月度±20%封顶，红涨绿跌；大类版颜色深浅表示该列内涨跌幅大小。
