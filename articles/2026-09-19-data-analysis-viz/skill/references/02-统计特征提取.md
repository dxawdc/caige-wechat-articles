# 02 统计特征提取

统计特征不是"把数字算一遍"，而是**为后面的图表和结论提供选型依据**。每算一个量，都要能回答："这个数指向什么观察？它应该用哪张图讲？"

## 目录

1. 提取顺序
2. 单变量：集中趋势
3. 单变量：离散程度
4. 单变量：分布形态
5. 集中度与长尾
6. 双变量：关系
7. 分组对比
8. 时间序列特征
9. 分布形态 → 图表映射
10. 特征清单输出模板

## 1. 提取顺序

严格按这个顺序，前一步的结果决定后一步用什么方法：

1. **先看类型**：分类 / 顺序 / 时间 / 数值。
2. **单变量分布**：集中趋势 + 离散程度 + 形态。
3. **异常与长尾**：这一步决定后面用均值还是中位数。
4. **双变量关系**：数值-数值、分类-数值、分类-分类，三类走三种方法。
5. **分组对比**：把总体拆成有业务含义的组。
6. **时序特征**：只有存在时间维度时做。
7. **收敛为候选指标**：交给第 4 步（关键指标识别）。

## 2. 单变量：集中趋势

| 统计量 | 什么时候用 | 注意 |
|---|---|---|
| 均值 | 分布近似对称、无极端值 | 被极端值牵动，偏态数据会误导 |
| 中位数 | 偏态分布、含极端值（收入、时长、金额） | **长尾业务数据的默认选择** |
| 众数 | 分类变量、离散取值集中 | 可能不唯一；连续变量需先分箱 |
| 截尾均值 | 剔除两端极值后的均值 | 要说明截尾比例 |
| 几何均值 | 增长率、倍数类指标的平均 | 用于计算复合增长 |
| 加权均值 | 各组样本量差异大 | 必须用加权，不能用简单平均 |

**判断口径**：看偏度绝对值。|偏度| < 0.5 近似对称可用均值；|偏度| ≥ 1 用中位数并以分位数补充。

## 3. 单变量：离散程度

| 统计量 | 含义 | 何时必看 |
|---|---|---|
| 标准差 | 平均偏离程度 | 对称分布 |
| 方差 | 标准差的平方 | 需要分解/比较时 |
| 四分位距 IQR | Q3 − Q1，中间 50% 的宽度 | 偏态分布的主选 |
| MAD | 中位数绝对偏差 | 含极端值时比标准差稳健 |
| 极差 | 最大值 − 最小值 | 快速感知量级；对极端值极敏感 |
| 变异系数 CV | 标准差 / 均值 | 跨量纲、跨量级比较波动性 |
| 标准误 | 样本均值的波动 | 画误差线、置信区间 |

**必须同时给出的组合**：最小值、P25、中位数、P75、最大值。只有均值±标准差会掩盖双峰和长尾。

对偏态分布还要给出 **P90 / P95 / P99**，因为业务上关心的往往是尾部。

## 4. 单变量：分布形态

| 特征 | 检测 | 含义 |
|---|---|---|
| 偏度 Skewness | > 0 右偏（长尾在右），< 0 左偏 | 右偏常见于时长、金额、频次 |
| 峰度 Kurtosis | > 3 尖峰厚尾 | 极端值比正态分布多 |
| 多峰 | 直方图/KDE 目视 | 很可能混了两个不同群体，应分组重看 |
| 零膨胀 | 0 值占比异常高 | 很多用户"没发生行为"，这是业务事实不是脏数据 |
| 有界性 | 取值上限/下限被顶满 | 如评分全 5 分，可能是指标设计问题 |

**多峰是最容易被均值掩盖的特征**，一旦发现多峰，优先做分组拆解而不是继续优化单变量统计量。

## 5. 集中度与长尾

适用于用户、金额、事件次数等高度倾斜的数据：

| 统计量 | 公式/含义 | 用途 |
|---|---|---|
| Top-N 占比 | 前 N 个实体占总量的比例 | 最直观，业务沟通首选 |
| 基尼系数 Gini | 0 完全平均，1 完全集中 | 跨群体比较集中度 |
| 赫芬达尔指数 HHI | 各份额平方和 | 市场/品类集中度 |
| 帕累托比 | 前 20% 贡献的比例 | 快速判断是否"二八分布" |
| 零值占比 | 取值为 0 的实体比例 | 判断分母是否被稀释 |

**集中度高不等于不好**，可能是设计使然（头部创作者生态），也可能是风险（单一大客户）。结论必须落到业务判断上。

## 6. 双变量：关系

按变量类型选方法，不要一律算 Pearson。

| 变量组合 | 方法 | 说明 |
|---|---|---|
| 数值 × 数值 | Pearson r | 仅适合线性、无极端值、近似正态 |
| 数值 × 数值（偏态/有异常） | Spearman ρ 或 Kendall τ | 基于秩，稳健 |
| 数值 × 数值（非线性） | 分箱后看均值走势、互信息 | Pearson 会低估非线性关系 |
| 分类 × 数值 | 组间均值/中位数对比 + 效应量 | 不要太早做 t 检验 |
| 分类 × 分类 | 列联表 + 卡方 + Cramér's V | Cramér's V 给强度，卡方给存在性 |

**必须守住的边界：**

- **相关不等于因果。** 图上画了回归线不等于证明了作用机制。
- 报告相关系数必须同时给**样本量**和**置信区间**，单独一个 r 值信息量很低。
- 相关系数对异常值极敏感，去掉极端点再算一遍看是否稳定。
- **辛普森悖论**：总体相关方向可能与分组内相关方向相反。当存在明显分层变量时，必须分组重算。
- 扫描大量分组组合找"显著"结果会产生假阳性，要么控制多重检验，要么把结论标为待验证假设。

## 7. 分组对比

分组是发现结构最有效的操作，比看总体统计量有用得多。

**分组维度优先级**：

1. 时间（时期、周次、季节）
2. 关键业务属性（渠道、平台、地区、版本、品类）
3. 用户分层（新/活跃/回流/流失、付费档位、等级段）
4. 行为特征（重度/中度/轻度）

**对比要点：**

- **同时报规模与比率。** 只看比率会漏掉基数变化（小基数高比率往往是噪声）。
- **先看效应量，再看显著性。** 样本极大时任何微小差异都"显著"，但可能毫无业务意义。
- **共同趋势检查**：对比两组时，先确认它们在干预前是否平行，否则差异可能来自既有趋势。
- 分组后每组的样本量要报出来，小于 30 的组结论要谨慎。

## 8. 时间序列特征

| 特征 | 方法 | 图型 |
|---|---|---|
| 趋势 | 移动平均、线性拟合、Theil-Sen | 折线 + 趋势线 |
| 季节性 | 按周期分组对比、季节分解 | 折线分面 / 热力图 |
| 周期性 | 自相关函数 ACF | 自相关图 |
| 波动 | 滚动标准差 | 折线 + 波动带 |
| 变化点 | 目视 + 分段均值对比 | 折线 + 竖直标注 |
| 增速 | 环比、同比、CAGR | 柱状 + 折线组合 |

**对齐规则：**

- 同比（YoY）消除季节性；环比（MoM/QoQ）看短期动能。两者不能混用。
- 比较不同长度周期时，要么用日均，要么用总量但标注周期长度。
- 时间轴必须连续，缺失周期要显式留空或标注，**不要用折线直接跨过缺口**。
- 预测要给出区间，不只给点估计；基线至少对比"季节性朴素法"（用去年同期值）。

## 9. 分布形态 → 图表映射

这是把统计特征转成可视化的关键桥梁：

| 提取到的特征 | 推荐图表 | 理由 |
|---|---|---|
| 单一集中、近似对称 | 直方图 / 箱线图 | 位置通道表达最准确 |
| 明显偏态、有长尾 | 箱线图 + 对数轴 / 分位数柱状图 | 避免长尾压扁主体 |
| 双峰或多峰 | 分组密度图 / 分面直方图 | 揭示被均值掩盖的群体结构 |
| 高集中度（二八） | 排序条形图 + 累计曲线（帕累托图） | 同时看排名与累计贡献 |
| 两个数值变量线性相关 | 散点图 + 回归线 + 置信带 | 位置通道 ×2，最优 |
| 两个数值变量非线性 | 分箱散点 / 六边形分箱图 / 热力图 | 避免点重叠遮蔽密度 |
| 分类 × 数值 | 分组柱状图 / 箱线图 / 蜂群图 | 比较中心与离散 |
| 分类 × 分类 | 热力矩阵 / 堆叠条形图 | 密度用色彩表达 |
| 多个变量相关性 | 相关性热力矩阵 / 散点图矩阵 | 一屏看全 |
| 时间趋势 | 折线图 / 面积图 | 位置通道表达变化最准确 |
| 时间 + 分类 | 多系列折线 / 小倍数分面 / 热力图 | 按系列数选择 |
| 时间 + 分类 + 数值 | 堆叠面积 / 河流图 | 复合目的 |

## 10. 特征清单输出模板

```markdown
## 统计特征清单

### 单变量
| 字段 | 类型 | 计数 | 均值 | 中位数 | P25 | P75 | P95 | 标准差 | 偏度 | 极值 |
（偏态字段以中位数与分位数为准，均值仅作参考）

### 分布形态
- 字段 A：右偏（偏度 __），呈长尾，P95 是均值的 __ 倍 → 建议箱线图/对数轴
- 字段 B：双峰 → 建议按 __ 分组重看

### 集中度
- 前 10% 的 __ 贡献了 __% 的总量 → 帕累托图

### 双变量
| 变量对 | 方法 | 统计量 | 样本量 | 是否稳健（去极值后） | 备注 |

### 分组对比
| 分组维度 | 组数 | 各组规模 | 主要差异 | 效应量 | 是否需分层重算 |

### 时序
- 趋势：__；季节性：__；变化点：__
```

## 检查清单

- 偏态字段用中位数而不是均值汇报了吗？
- 分位数（P25/P75/P95）给出来了吗？
- 有多峰吗？如果有，是不是该先分组？
- 相关系数带样本量了吗？去极值后还成立吗？
- 有没有可能的分层变量导致辛普森悖论？
- 分组对比有没有同时报规模和比率？
- 时间轴连续吗？缺失周期有没有显式留空？
- 预测给区间了吗？
- 每个统计量都对应了图表建议吗？
