# 04 图表匹配

图表选择不是审美问题，是**论证效率**问题。同一份数据用不同图表呈现，读者得到的结论可能完全不同。

## 1. 三步定图型

### 第 1 步：这句话想表达什么意图？

把要讲的结论写成一个句子，然后判断它属于哪一类：

| 意图 | 典型句式 |
|---|---|
| 比较 | "A 比 B 高 / 哪个最大" |
| 趋势 | "随时间怎么变" |
| 占比 | "各部分占整体的多少" |
| 分布 | "值集中在哪、有多分散、有几群" |
| 相关性 | "X 和 Y 有关系吗" |
| 层级 | "整体由哪些部分构成，逐层拆开" |
| 关联 | "谁和谁连在一起、怎么流动" |
| 逻辑示意 | "流程是什么、因果关系怎样" |
| 地理 | "在哪里、空间上怎么分布" |
| 复合 | "同时看两件以上的事" |

**一句话里只允许一个意图。** 出现两个，就画两张图。

### 第 2 步：字段是什么类型？

- 分类 / 顺序 / 时间 / 数值 / 标识 / 文本（见 `01-数据概览与清洗.md` 第 3 节）
- 有几个系列？几个类别？几个数据点？

### 第 3 步：用视觉通道准确性校验

默认选位置通道（柱状图、折线图、散点图）。只有位置通道表达不了（如二维以上的密度、层级、关联）时才升级到面积、颜色、形状通道。

**只有一句话判断图型选得对不对：读者能不能在 3 秒内读出你要讲的那个数字或方向。**

## 2. 视觉通道的准确性排序

人类对不同视觉通道的感知精度有稳定的优劣顺序（Cleveland & McGill 的经典结论，经受住反复验证）：

```text
位置  >  长度  >  角度 / 斜率  >  面积 / 体积 / 密度
（最准）                                    （最不准）
```

**按数据类型细分**（Mackinlay 的整理）：

| 通道 | 分类型数据 | 顺序型数据 | 数值型数据 |
|---|---|---|---|
| 位置 | 最佳 | 最佳 | 最佳 |
| 长度 | 好 | 好 | 好 |
| 形状 | 第二位（区分类别很有效） | 不适用 | 不适用 |
| 角度 / 面积 | 不适用 | 不适用 | 可用于连续变量，但精度差 |
| 颜色（色相） | 适合区分类别 | 一般 | 不适合表达数值大小 |
| 颜色（明度渐变） | 不适用 | 适合 | 适合表达数值大小 |

**三条直接可用的推论：**

1. **柱状图在表现绝对数值时优势明显**，因为它用的是位置/长度通道。同样的数据换成饼图、圆面积图，读者很难一眼看出差异到底有多少。
2. **分类变量不要映射到面积通道。** 用不同颜色或形状区分类别，而不是让面积大小代表类别。
3. **数量差异小时，避免用面积/角度类图表。** 饼图在各类占比接近时几乎无法分辨。

## 3. 十大意图与候选图表

### 3.1 比较

**初衷**：对比两个或以上类别的数值。

| 候选 | 适用 | 边界 |
|---|---|---|
| 柱状图（垂直） | 类别 ≤ 12，标签短 | 绝对数值首选；**基线必须从 0 开始** |
| 条形图（水平） | 类别多、标签长 | 排序后更易读；支持较长分类名 |
| 分组柱状图 | 每类有 2–4 个子系列 | 子系列 ≥ 5 时改用分面或热力图 |
| 堆叠柱状图 | 同时看总量与构成 | 只适合比较总量和底部一段；中间段难度量大 |
| 百分比堆叠柱状图 | 比较构成比例 | 必须每根柱合计 100% |
| 棒棒糖图 | 类别多、要弱化视觉重量 | 比柱状图更轻盈，数值感稍弱 |
| 雷达图 | 3–8 个维度的形态对比 | 维度超过 8 会视觉混乱；顺序影响形状 |
| 平行坐标图 | 多维度、多实体 | 需要一定视觉素养 |
| 斜率图 | 两个时点/两种状态的对比 | 展示变化方向比展示绝对量更强 |
| 圆面积图 | 无坐标轴、设计自由度大 | **精度差**，需把数据映射到面积而非半径 |
| 南丁格尔玫瑰图 | 想强调视觉冲击 | 有放大差异的倾向，需说明编码方式 |

### 3.2 趋势

**初衷**：展示数据随时间的变化。**必须有一个时间变量。**

| 候选 | 适用 | 边界 |
|---|---|---|
| 折线图 | 连续时间、看趋势与拐点 | 首选；时间轴必须从左到右 |
| 多系列折线图 | 2–5 条线对比 | 超过 5 条考虑小倍数分面或高亮一条其余转灰 |
| 面积图 | 强调累计量/总量 | 多系列时下层被遮盖 |
| 堆叠面积图 | 同时看总量与构成随时间变化 | **不适合比较中间层的大小** |
| 河流图 | 构成随时间流动 | 视觉吸引力强，精读困难 |
| 阶梯图 | 取值在区间内恒定（利率、档位、价格） | 不要用折线代替 |
| 蜡烛图 | 有开高低收四值 | 金融场景专用 |
| 瀑布图 | 看增减过程如何累积成总量 | 不是趋势图，但常用于时间序的增量分解 |
| 柱状图（时间轴） | 离散时间点、类别少 | 时间点超过约 20 个改用折线 |
| 动态/动画图 | 时间维度太多，静态画不下 | 需要交互载体；静态导出只保留关键帧 |

### 3.3 占比

**初衷**：某部分占整体的多少。**前提：所有部分必须构成一个 100% 的整体。**

| 候选 | 适用 | 边界 |
|---|---|---|
| 饼图 / 环图 | 类别 ≤ 5，且差异明显 | **类别多、差异小时禁用**；必须合计 100% |
| 环形图 | 中心可放总量标签 | 同上 |
| 百分比堆叠条形图 | 类别多、要横向排列 | 比饼图更能容纳类别 |
| 华夫饼图 | 用方块数量表达占比，直观 | 需要总数可被网格数整除或近似 |
| 象形图 / 图标堆叠 | 面向大众、要接近性 | 精度低，适合传播不适合分析 |
| 树图 Treemap | 层级 + 占比 | 面积通道精度低，适合看层级不看精确占比 |
| 桑基图 | 占比 + 流向 | 也属于"关联"类 |

**饼图的三条硬规则：**

1. 所有扇形的数据必须构成 100% 的整体。只是挑几个类别对比时，用柱状图。
2. 类别数 ≤ 5；超过就合并为"其他"或改用条形图。
3. 各类占比接近时改用柱状图——人对高度的感知远准于对扇形角度的感知。

### 3.4 分布

**初衷**：数据集中在哪、有多分散、有几个峰。

| 候选 | 适用 | 边界 |
|---|---|---|
| 直方图 | 单变量数值分布 | **与柱状图本质不同**：柱状图比类别，直方图比区间频数；柱子应紧贴 |
| 密度图 KDE | 平滑看形状、比较多组 | 平滑带宽会改变观感，需说明 |
| 箱线图 | 比较多个分组的分布 | 展示中位数与四分位，隐藏多峰；可叠加散点 |
| 小提琴图 | 看形状 + 分布 | 需要更多读者素养 |
| 蜂群图 / 抖动散点 | 样本量中等时展示每个点 | 点太密集时失效 |
| 累积分布曲线 | 关心"低于某值的比例" | 业务沟通力强 |
| 人口金字塔 | 两个方向的分组分布 | 双向条形图的特例 |
| 二维密度图 / 六边形分箱 | 两个数值变量的联合分布 | 点太多时的散点替代 |
| 3D 曲面 | 两个自变量 + 一个因变量 | 透视会扭曲，仅用于探索 |

**关键判断**：样本量 < 100 时先画散点（每个点都可见）；100–1 万用直方图/箱线图；> 1 万用密度图或分箱。

### 3.5 相关性

**初衷**：两个或更多变量之间有没有关系、方向如何、强度多大。

| 候选 | 适用 | 边界 |
|---|---|---|
| 散点图 | 两个数值变量 | 最准确（双位置通道）；点过多时改密度 |
| 散点图 + 回归线 + 置信带 | 要说明趋势与不确定性 | 置信带比单条线更严谨 |
| 气泡图 | 第三、第四个变量（尺寸、颜色） | 尺寸要映射到**面积**；变量不超过 4 个 |
| 散点图矩阵 | 多组变量两两关系 | 变量 ≤ 6 |
| 相关性热力矩阵 | 变量间的相关强度总览 | 必须标注相关方法与样本量 |
| 平行坐标图 | 多变量的模式分层 | 需要对变量做归一化 |

**散点图的边界：**

- 两个轴都必须是**连续数值**。把分类变量放到轴上会得到无法解读的图。
- **点超过约 5000 个时改用**：六边形分箱图、二维密度图、半透明点、或抽样。
- 画了回归线就要交代：样本量、拟合方法、是否去极值、是否有分层变量。

### 3.6 层级

**初衷**：整体如何逐层拆分为部分（父子、包含关系）。

| 候选 | 适用 | 边界 |
|---|---|---|
| 树图 Treemap | 层级 + 占比，空间利用率高 | 矩形面积通道精度低；适合发现大块 |
| 旭日图 | 层级 + 占比，径向展开 | 层级 ≤ 3 层，否则细环不可读 |
| 打包圆形图 | 层级 + 占比，形状圆润美观 | 空间利用率低于树图 |
| 树状图（树形） | 只看结构不看数值 | 节点多时连线会缠绕 |
| 径向树状图 | 层级深、想节省横向空间 | 文字朝向要处理 |
| 沃罗诺伊 / 蜂巢图 | 层级 + 占比，视觉新颖 | 读者素养要求高 |

用树图时注意：**父节点面积必须等于子节点面积之和**，否则比例不可信。

### 3.7 关联

**初衷**：谁和谁有关系、关系有多强、流量怎么走。

| 候选 | 适用 | 边界 |
|---|---|---|
| 网络图（力导向） | 节点-边关系、社群结构 | 节点 > 200 时变毛线团，需筛选度阈值 |
| 弧长连接图 | 视觉上能表达"流量粗细" | 线条交叉多时难读 |
| 桑基图 | 多级流向 + 量级 | **每个节点的流入总量必须等于流出总量** |
| 邻接矩阵 | 密集关系、要精确读取 | 精度高但需要读者素养 |
| 和弦图 | 双向关系强度 | 类别 ≤ 20 |

### 3.8 逻辑示意

**初衷**：说明流程、因果、包含关系，而不是展示数据量。

| 候选 | 适用 |
|---|---|
| 流程图 | 步骤顺序 |
| 韦恩图 | 集合的包含与交叠 |
| 鱼骨图 | 归因分析（人机料法环） |
| 决策树图 | 判断路径 |
| 时间轴 | 事件序列（不是趋势） |
| 甘特图 | 任务的时间跨度与并行关系 |

这类图表**不用来承载数值精度**，承载数值的部分要单独用统计图表表达。

### 3.9 地理

**初衷**：空间分布。

| 候选 | 适用 | 边界 |
|---|---|---|
| 分级填色地图 | 数值在区域间的分布 | 面积大的区域视觉权重被高估 |
| 变形地图（Cartogram） | 用面积表达数值而非地理面积 | 读者需适应 |
| 点密度地图 | 事件的绝对分布 | 会暴露高密度区（注意隐私） |
| 流向地图 | 地理上的流动 | 线条交叉多时难读 |
| 等高线 / 分层设色 | 连续场（气温、污染） | 专业场景 |
| 地图 + 内嵌图表 | 地图上叠加饼图/柱状图 | 内嵌图形数量要控制 |

**地图的天然缺陷**：面积大的地区不一定重要。涉及中国地图时必须使用符合国家标准的正确地图数据，不得出现领土缺失或错误绘制。

### 3.10 复合目的

**初衷**：一张图同时回答两三个问题。

| 组合 | 候选 | 常见错误 |
|---|---|---|
| 趋势 + 构成 | 堆叠面积图、河流图、100% 堆叠面积图 | 用堆叠面积图比较中间层大小（做不到） |
| 趋势 + 排名 | 排序折线图、动态追逐柱状图、凹凸图 | 用多系列折线比较排名（交叉点难读） |
| 趋势 + 数值分解 | 瀑布图、柱线组合图（柱=量，线=率） | 双轴随意缩放，放大或抹平差异 |
| 分布 + 相关性 | 气泡图、散点矩阵、密度热力图 | 变量超过 4 个 |
| 层级 + 占比 | 多层树图、旭日图 | 层级过深 |
| 关系 + 时间 | 动态网络图 | 静态导出后信息丢失 |

**双轴图的硬约束**：左右轴必须标注清楚，且不要通过调整轴范围来人为制造或消除两个系列的"同步感"。如果没有明确理由，优先用**两个上下对齐的独立子图**（共享横轴）替代双轴。

## 4. 决策树：按意图逐条走

### 比较

```text
类别数 ≤ 12？
├─ 是 → 标签短？ → 柱状图
│               └─ 标签长？ → 条形图（排序）
└─ 否 → 取 Top-N + 其他 → 条形图（排序）
        └─ 还要看构成 → 堆叠条形图 / 百分比堆叠
```

### 趋势

```text
有连续时间变量？
├─ 否 → 不是趋势图，回到"比较"或"分布"
└─ 是 → 系列数？
        ├─ 1 条 → 折线图 / 面积图（强调总量）
        ├─ 2–5 条 → 多系列折线（高亮 1 条，其余转灰）
        └─ > 5 条 → 小倍数分面 / 热力图（时间 × 系列）
```

### 占比

```text
所有部分合计 = 100%？
├─ 否 → 不能用饼图/百分比堆叠 → 改柱状图比较
└─ 是 → 类别数？
        ├─ ≤ 5 且差异明显 → 饼图 / 环图
        ├─ 6–12 → 百分比堆叠条形图 / 华夫饼图
        └─ > 12 → 条形图（排序）+ 累计曲线
```

### 分布

```text
样本量？
├─ < 100 → 散点 / 蜂群图（每个点可见）
├─ 100 – 1万 → 直方图 / 箱线图（分组比较）
└─ > 1万 → 密度图 / 分箱热力图
```

### 相关性

```text
两个变量都是连续数值？
├─ 否 → 分类×数值走"分组比较"（分组柱状/箱线图）
│        分类×分类走热力矩阵
└─ 是 → 点数？
        ├─ < 5000 → 散点图（+ 回归线 + 置信带）
        └─ ≥ 5000 → 六边形分箱 / 二维密度 / 抽样散点
```

### 多变量

```text
变量数？
├─ 3–4 → 气泡图（尺寸映射到面积 + 颜色映射类别）
├─ 5–6 → 散点图矩阵 / 平行坐标
└─ > 6 → 相关性热力矩阵 → 再选出代表性变量深入
```

## 5. 按数据规模调整图型

| 规模 | 调整 |
|---|---|
| 类别 > 20 | 取 Top-N 合并其余为"其他"；或改用条形图 + 滚动 |
| 时间点 > 50 | 折线代替柱状；可加移动平均线 |
| 时间点 > 300 | 改用热力图（时间 × 周期）或条带图 |
| 散点 > 5000 | 密度图 / 分箱 / 抽样 / 半透明 |
| 系列 > 5 | 小倍数分面；或高亮 1 条其余转灰 |
| 变量 > 6 | 先降维或选代表，不要硬塞一张图 |
| 层级 > 3 | 拆分；或改用可交互的树图 |
| 行数 > 100 万 | 先聚合到图表能承载的粒度，再画 |

**核心原则：图表的承载能力有限，超过就先聚合，而不是把所有数据硬画上去。**

## 6. 图表误用与反模式

| 反模式 | 为什么错 | 正确做法 |
|---|---|---|
| 柱状图纵轴不从 0 开始 | 柱子高度比例失真，放大差异 | 柱状图基线必须为 0 |
| 折线图强行从 0 开始（数据远离 0 时） | 抹平真实变化 | 折线图允许非零基线，但必须标注 |
| 饼图类别过多 | 小扇形不可读，比例无法比较 | 合并为"其他"或改条形图 |
| 饼图用于非整体数据 | 违反了占比图的前提 | 改柱状图 |
| 用面积表现分类变量 | 分类变量应用颜色/形状，不该用连续通道 | 换颜色编码 |
| 数据映射到半径而非面积 | 面积按平方放大，差异被夸大 | 先开方再作为半径 |
| 3D 柱状图 / 3D 饼图 | 透视扭曲比例（"说谎指数"可能高达十几倍） | 用 2D；确有空间属性时才用 3D |
| 玫瑰图未说明编码方式 | 按角度编码和按高度编码会得到完全不同的观感 | 明确说明，并注明其放大差异的倾向 |
| 混淆柱状图与直方图 | 一个比类别，一个比区间频数 | 直方图柱子紧贴、标明区间 |
| 混淆折线图与密度图 | 一个表达趋势，一个表达分布 | 按意图选型 |
| 双轴随意缩放 | 制造虚假的"同步"或"背离" | 上下对齐双子图，或标注轴范围理由 |
| 堆叠面积图比较中间层 | 中间层基线不齐，无法比较 | 改多条折线或分面 |
| 时间轴从左到右反向 | 违背阅读习惯，趋势被读反 | 时间从左到右 |
| 颜色方向反了 | 深色被误认为小值 | 深色 = 大值，浅色 = 小值 |
| 分类数据用同色系深浅 | 类别区分度不够 | 分类用不同色相 |
| 连续数据用多种色相 | 无法判断数值高低 | 连续值用单一色相的明度渐变 |
| 网格线/边框过重 | 数据墨水比低，干扰阅读 | 删除无意义网格与边框 |
| 只给均值不给分布 | 掩盖长尾、多峰、极端值 | 补分位数或箱线图 |

## 7. 图表选择速查矩阵

横轴：数据关系；纵轴：推荐排序（第一个为首选）。

| 意图 | 首选 | 次选 | 慎用 |
|---|---|---|---|
| 比较（类别少、标签短） | 柱状图 | 棒棒糖图 | 饼图 |
| 比较（类别多、标签长） | 条形图（排序） | 点图 | 圆面积图 |
| 比较（多子系列） | 分组柱状图 | 折线（按系列颜色） | 堆叠柱状（比较非底部段） |
| 趋势（单系列） | 折线图 | 面积图 | 柱状图（点多时） |
| 趋势（多系列） | 多系列折线 | 小倍数分面 | 堆叠面积（比较中间层） |
| 占比（少类别） | 饼图 / 环图 | 华夫饼图 | 树图（要精确占比时） |
| 占比（多类别） | 条形图 + 累计曲线 | 百分比堆叠条形图 | 饼图 |
| 分布（单变量） | 直方图 | 箱线图 / 密度图 | 饼图 |
| 分布（分组比较） | 箱线图 / 蜂群图 | 小提琴图 | 只报均值 |
| 相关性（双变量） | 散点图 + 回归线 | 气泡图（第三方变量） | 双折线图 |
| 相关性（多变量） | 相关性热力矩阵 | 散点图矩阵 | 3D 散点 |
| 层级 | 树图 / 旭日图 | 打包圆形图 | 多层饼图 |
| 关联 | 桑基图 / 网络图 | 邻接矩阵 | 复杂毛线团 |
| 逻辑 | 流程图 / 鱼骨图 | 甘特图 | 用柱状图代替流程 |
| 地理 | 分级填色地图 | 变形地图 | 面积权重被误读 |
| 复合 | 上下对齐双子图 | 气泡图 / 堆叠面积 | 双轴随意缩放 |

## 8. 反向自检

选完图必须过一遍：

1. 这张图**在回答哪个问题**？能一句话说出来吗？
2. 读者能不能在 **3 秒内**读出结论？
3. 坐标轴有没有**误导性截断或缩放**？
4. 数据映射到的是**正确通道**吗（面积 vs 半径、长度 vs 面积）？
5. 图型与**数据类型匹配**吗（分类变量有没有被塞进连续通道）？
6. 有没有**信息量过载**（类别太多、线条缠绕、点重叠）？
7. **图例离数据近吗**，读者需要来回看吗？
8. 如果用**黑白打印**，还能读懂吗？色盲用户能区分吗？
9. 标题写的是**结论**还是字段名？
10. 有没有交代**样本量、口径、数据来源**？
