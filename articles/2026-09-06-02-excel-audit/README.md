文章标识：**02-excel-audit**。作者：才哥AGI。全部业务数据为教学模拟。

## 本包解决什么问题

4 份 Excel → 文件校验 → 原值与来源保留 → 无效/重复/冲突/可用记录。

预期结果：**3 份文件接受、1 份拒收；8=1 无效+1 重复+2 冲突+4 可用；可用金额 1200 元。原始金额中的“待补”不会被覆盖。**

## 独立下载与运行

[仅下载本篇 ZIP](https://raw.githubusercontent.com/dxawdc/caige-wechat-articles/main/downloads/02-excel-audit_v1.1.1.zip)。解压后进入 `02-excel-audit_v1.1.1` 目录，使用 Python 3.12：

```powershell
python -m pip install -r requirements_v1.1.1.txt
python "运行_02_Excel合表审计_v1.1.1.py"
```

专属入口先复制本包材料到 `运行结果/02-excel-audit/`，再运行本篇基础和进阶脚本。包内原始样例与清单保持不变；重复运行会更新该输出目录的教学结果。请勿将真实业务文件放入这个输出目录。

基础脚本：`案例与绘图_v1.1.1.py`。进阶脚本：`进阶案例_v1.1.0.py`。绘图工具及部分依赖跨篇复用，核心案例、输入数据、结果和本包入口属于本篇。
