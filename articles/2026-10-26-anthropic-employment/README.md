# Anthropic内部就业报告配套资料

版本：v1.3.0；更新时间：2026-10-26。

本资料提供五张配图：初级技术人员占比、六类岗位人均产出、AI使用规模、管理与协作变化、AI任务检查流程，以及指标口径、计算结果、绘图源码、封面PNG及可编辑SVG模板。

数据来自Anthropic于2026年10月16日发布的《How employment is changing at Anthropic》：
https://www.anthropic.com/research/employment-at-anthropic

图1采用报告正文公布的取整端点，分别以技术新招聘人数、技术在职人数为分母。图2采用官方原图3明确标注的六个终点倍数，基期为2025年12月；图3分开展示月度会话次数和代理/人类工时比；图4区分会话占比与会议时长增幅；图5是作者整理的实践流程，沿用原文件名“图2_任务检查顺序.png”。

v1.3.0以初级技术招聘占比27%→9%重做横版和方版手绘数据封面，采用统一0—30%尺度。五张正文图沿用方格纸、钢笔标题、彩铅排线、数字圈注和胶带贴纸。数据坐标与排线范围由原始数据确定，轻微手绘线条只作用于视觉样式。

## 使用方法

安装Python 3.10或更新版本，执行：

```powershell
python -m pip install -r requirements.txt
python 绘图.py
```

绘图脚本优先使用系统中文字体，生成正文五张图；缺少封面模板时创建横版与方版可编辑SVG及对应PNG，已有模板直接复用。封面数据读取自“数据/数据与来源.json”。可在矢量编辑器中单独修改SVG里的文字、形状和配色。

手绘主题优先使用系统的KaiTi/STKaiti和Comic Sans MS字体；其他系统按脚本的字体列表回退，字形效果可能略有差异。排线采用固定随机种子，数据比例可复现。

## 文件说明

- `数据/数据与来源.json`：原报告入口、数据端点、分母、核对位置和解释范围。
- `绘图.py`：图表、流程图与封面模板的可复现源码。
- `手绘主题.py`：笔记纸、手写字体、排线及圈注实现。
- `配图/`：正文图、手绘数据封面、SVG模板及PNG。
- `物料清单.json`：文件大小与SHA-256校验值。

绘图署名：可以叫我才哥。封面展示报告中初级技术招聘占比的前后端点。
