# 黄金白银这10年：从上金所到周大福柜台

版本：v1.0.2 ｜ 更新时间：2026-09-19 ｜ 配套公众号文章《黄金白银这10年：从上金所到周大福柜台，我用公开数据把价格画明白了》

用公开接口采集贵金属价格数据并绘图：国际金银十年日线、上海黄金交易所官方日行情，以及周大福、周六福、老凤祥、周生生、老庙黄金、菜百六家金店近两年的足金饰品挂牌价。

## 目录结构

```
precious-metals_v1.0.2/
├── scripts/                 采集、清洗与绘图脚本
│   ├── 采集原始数据.py       拉取交易所/期货/品牌金价原始数据
│   ├── 清洗与指标.py         去重、剔除越界、修正离群值、计算指标
│   ├── 提取叙事关键点.py     输出文中引用的关键节点
│   ├── 图表风格.py           matplotlib 统一配色与字体
│   ├── 绘图_00_动图.py       近十年金银走势动态曲线图（GIF，需 Pillow）
│   ├── 绘图_01至05.py        图01~图06
│   ├── 绘图_06至09.py        图05/图07~图09
│   └── 制作封面.py           1200x510 封面（本文实际封面为作者另换的图02裁切版 封面_v1.0.1.jpg）
├── data/clean/              清洗后的整洁 CSV（可直接复现全部图表）
├── images/                  正文 9 张图、近十年走势动图 GIF 与封面
└── 物料清单_v1.0.2.json     文件清单与 SHA-256
```

## 使用方法

```bash
python -m pip install pandas numpy matplotlib lxml pillow
python scripts/采集原始数据.py     # 联网采集，输出 data/raw/
python scripts/清洗与指标.py       # 输出 data/clean/ 与 输出/
python scripts/绘图_00_动图.py     # 输出配图/动图01_*.gif 与末帧 PNG
python scripts/绘图_01至05.py
python scripts/绘图_06至09.py
```

只想直接用数据的话，`data/clean/` 里的 CSV 已经对齐好日期，可以跳过采集直接画图。

## 数据口径与免责声明

- 数据全部来自公开接口：上海黄金交易所官网日行情、新浪财经期货行情接口、金投网行情页。
- **金店价格为挂牌参考价，不是成交价**，不含工费、折扣与活动优惠；不同城市门店执行价格可能不同。
- 清洗过程会剔除越界行、合并重复记录并修正明显的采集错误（脚本内有明细日志），但仍不保证无错漏，数据可能随时变化。
- 区间涨跌幅取决于起止日期选择，结论仅对本文所述区间成立。
- **本项目仅用于学习与技术演示，不构成任何投资建议**，贵金属价格波动剧烈，风险自担。
