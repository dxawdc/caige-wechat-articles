# A股一天的资金流向：公众号配套资料

对应公众号文章《我把A股一天的资金流向，做成了一组图》（2026-09-21 收盘数据）。

本文把 2026-09-21（周一）收盘后全市场 5195 只有效交易股票的资金流数据拉下来，用 10 张图拆开看：钱是什么时候进来的、集中在哪些票、流向了哪些行业、净额背后四档结构是什么样。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `scripts/` | 采集与绘图脚本（Python 3.10+），入口 `合并数据源.py` 拼装全市场数据、`绘图_资金结构图.py` 生成核心图 |
| `data/` | 当日数据：全市场资金流（含四档净额、市值、成交额）、行业资金流、分时资金流（上证指数口径 + 头部候选股） |
| `images/` | 文中 10 张图（含资金榜演变动图 GIF 及其末帧）与封面 |

## 数据来源与口径

- **四档净额、涨跌幅**：东方财富数据中心公开报表（`RPT_DMSK_TS_STOCKNEW`），字段含超大单/大单净额、涨跌幅、换手率。
- **成交额、市值**：腾讯行情（`qt.gtimg.cn`）。
- **分时资金流**：东方财富 `fflow/kline` 接口。分钟级四档资金流只对单只股票或单个指数提供；本文第二章用**上证指数（沪市）**的分时资金流还原"钱是什么时候进来的"节奏，全天主力净额 +30.6 亿（全市场口径为 +108.5 亿，差额主要来自深证主板与创业板）。
- 主力 = 超大单 + 大单；四档净额（超大单/大单/中单/小单）之和恒等于 0。

## 复现方式

采集与绘图脚本在原工作目录结构下运行（`绘图/` 与 `数据采集/` 平级，脚本内部用相对路径定位数据）。这里按资料库结构平铺为 `scripts/`、`data/`、`images/`，如需复现：

1. 新建 Python 3.10+ 虚拟环境，安装依赖（`pandas`、`numpy`、`matplotlib`、`PIL`，交互图另需 `plotly`）。
2. 把 `scripts/` 与 `data/` 放到同一工作目录（脚本 `_common.py` 会向上找 `数据采集/` 目录，可按需要调整路径常量）。
3. 采集脚本需在交易日收盘后运行，接口可能触发风控；分时接口 `fflow/kline` 为极小配额接口，被拒后需静默 10 分钟以上再续采（脚本已内置 `--wait`/`--gap`/`--retry-wait` 参数）。

数据为公开行情接口导出，供学习和研究使用，不构成投资建议。
