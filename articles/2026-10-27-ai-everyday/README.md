# 普通人用AI，可以做什么？36个全场景案例全公开，建议收藏

版本：v1.1.0｜日期：2026-10-27｜作者：才哥AGI

这份资料提供36项场景提示词、26张正文配图、横版与方版封面、两套可编辑SVG模板及其PNG、生图提示词、工具来源和素材说明。

## 从这里开始

1. 打开[场景提示词](场景提示词.md)，按日常查询、办公内容、视觉影音、开发自动化选择一个任务，将资料、限制与验收条件改成自己的情况。
2. 打开[配图总览](配图总览.html)，查看配图与封面。浏览器可以直接打开本地HTML。
3. 横版与方版模板位于[配图](配图/)，用支持SVG的编辑器分别修改文字和图形。重新生成模板可运行 `python 源码/生成封面模板.py`，仅使用Python标准库。
4. [生图提示词](源码/生图提示词.json)、[扩展场景提示词](源码/扩展场景生图提示词.json)与[封面修订提示词](源码/封面修订提示词.json)记录本次内置imagegen的生成与修改要求。

## 素材与来源

本次生成图为工作场景示意，图内标明AI生成；封面是概念插画。项目截图、代码动画、角色渲染来自作者已有实践，行情数值属于原截图时点。相关矩阵来自作者已有图表案例，使用教学示例数据。Android场景对应测试工程。

[素材说明](素材说明.json)记录各文件性质；[工具来源](工具来源.md)提供官方入口与功能说明；[物料清单](物料清单.json)记录当前文件的SHA-256校验值。

配图中的第三方产品、游戏与角色标识用于案例介绍，相关权利归原权利人。复用时按素材性质和具体使用范围核对授权。
