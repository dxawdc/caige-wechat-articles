# 81组对称区间参数：收益回撤分布、相对持有与名次迁移

版本：v2.0.0 · 更新：2026-10-11 · 出品：可以叫我才哥

本资料用512890、515080、515100的历史日线和现金分红，独立研究价格均线择时。提供2020年至2026年9月的行情快照、2022年初至2026年9月底的回测、81组参数表、逐笔交易记录、6张正文图与封面素材。

## 复现

建议 Python 3.10+。本次在 Python 3.14 / Windows、Microsoft YaHei 字体环境验证。其他系统请安装微软雅黑、黑体或在绘图脚本中配置本机可用的中文字体。

```bash
python -m pip install -r requirements.txt
python 复现.py
```

运行入口使用随包冻结快照离线计算，依次验证总回报构建、生成回测和网格、独立账本复算、绘制本篇6张图。输出写入 `结果/` 和 `图片/`。单独运行 `python 绘制图表.py` 可从已有结果重绘本篇。

## 文件与计算口径

- `数据/总回报行情.json`：基金名称与逐日日线；`market_open/market_close` 为拆分校正的场内价，`dividend` 为每份现金分红，`open/close/high/low` 为理论总回报序列；2022年以前用于均线预热。
- `数据/总回报日线.csv`：可直接检查的同源明细；`来源.json` 提供采集接口和分红页面，`总回报口径核验.json` 保存分红事件及跨源核验。
- `回测研究.py`：持有、MA200/±5%、现金2%假设、每只ETF81组网格、历史时间留出、费用与决策滞后敏感性。
- `结果/研究结果.json`：账户路径与计算指标；`参数网格.csv`：full/train/test三个区间；`基准策略交易记录.csv`：标准策略每次买卖。
- `验收回测.py`：独立现金/份额账本、逐日对称区间信号、修改未来价格不影响此前结果、持有公式与前段独立选参核验。
- `图片/`：本篇6张图、无账号署名的AI概念封面及中文可编辑的横版/方版SVG模板；`封面设计.json` 保存提示词。

信号：空仓且收盘低于200日均线乘0.95时买入，持仓且收盘高于均线乘1.05时卖出。均线包含信号日收盘，标准方案下一交易日开盘执行，单边扣费0.03%，现金默认不计息，期末按市值计价。年化按自然日365.25折算，最大回撤使用日收盘账户净值。

分红按除息日开盘理论即时再投：当日因子 = 前日因子 × (1 + 每份分红 / 市场开盘价)。它允许小数份额、忽略现金到账等待和再投手续费。2024-01-15三只基金的收盘在腾讯与Yahoo之间有0.003—0.008元差异，主实验统一保留腾讯数据，核验表记录原差异。

网格为9种均线×9种对称偏离幅度，每只ETF81组；均线为60、90、120、150、180、200、220、250、300日，偏离幅度为0%、1%、2%、3%、4%、5%、6%、8%、10%。前段2022—2023年只按年化最高选参，后段2024年至2026年9月固定执行；两段从现金开始，均线用过去数据预热。该时间留出是2026年进行的事后历史研究。价格条件实验的结论适用于本文数据与设定；历史PE、股息率与债券轮换可作为独立扩展研究。

滞后敏感性：当日开盘使用1、2、3个交易日前的价格条件，结合当日已有仓位做决策；表示决策信息更滞后时的路径变化，并非将原订单队列机械后移。
