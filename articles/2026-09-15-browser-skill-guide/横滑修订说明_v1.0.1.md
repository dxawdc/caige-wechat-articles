# 代码横滑修订说明

版本：v1.0.1；更新时间：2026-09-15；状态：现有草稿已更新，待用户手机微信确认。

用户反馈v1.0.0在手机微信中代码自动换行。v1.0.0普通浏览器模拟通过不能证明手机微信横滑通过。

## 本次修改

- 保留Pygments内联语法高亮、11px字号、18px行高和源代码内容。
- `pre`恢复 `code-snippet__js code-snippet_nowrap` 标记；外层section保留 `code-snippet__fix`，不添加 `code-snippet__js`，避免外层被重新解析为会丢弃自定义字号的原生代码节点。
- pre、逐行code和高亮span增加 `white-space:pre!important` 与 `word-break/word-wrap/overflow-wrap:normal!important`。
- pre限定100%容器宽度并允许横向滚动；逐行code使用 `width:max-content!important;min-width:100%;max-width:none!important`，长行在代码块内部展开；外层防止撑宽全文。
- 删除行号列表的旧处理继续保留，没有重新引入ul/ol占位。

本篇v1.0.1渲染器是针对手机反馈的修订版。微信实际样式与编辑器处理尚不能完全由本地模拟代表，本文不将该修订写成已经得到真机确认的通用保证。

## 验收结果

1. 本地及API回读代码，与v1.0.0的13个代码块逐块比较；普通空格/NBSP按显示语义归一化后完全相同，语法颜色相同。
2. 1280px、390px、360px分别检查普通状态与注入换行CSS状态，共12种布局。所有源代码行均保持18px单行高度，长行可以滚动，文章本身不横向溢出。
3. 注入CSS是用于检验样式优先级的人工回归条件，不是从本次真实手机提取的微信CSS。在这一条件下旧版6个代码块出现换行，新版全部保持单行。
4. Chromium模拟触摸拖动，代码scrollLeft实际增加，并保存滑动前后截图；这不等于真实手机微信测试。
5. 现有草稿仅替换代码区样式；7张正文图片节点、其他文字及标题等保持当前草稿状态。图注实际间距仍为6px。
6. 微信API曾因当前草稿thumb_media_id为空返回40007。通过当前thumb_url核对封面像素与原图一致后，复用原永久素材ID完成更新；没有换图或新建草稿。
