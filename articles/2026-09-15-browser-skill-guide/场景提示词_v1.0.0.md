# BrowserSkill 场景提示词

版本：v1.0.0；更新时间：2026-09-15；状态：可复用模板，按实际页面调整。

1. **资料筛选**：使用 browser-skill 打开 http://127.0.0.1:8769/，搜索 Python、选择 Python 类别。核对当前结果后导出标题、类别、阅读分钟、日期，记录行数并截图。若普通点击无效，有限检查后说明问题。完成或受阻时结束本次会话。
2. **表单填写**：打开演示站 /#form，称呼填才哥，邮箱填 demo@example.com，主题选择AI工具实操。核对字段后截图，停在提交前。
3. **手机布局**：打开演示站 /#mobile，分别保留桌面和iphone-14模拟截图，检查卡片是否重排以及是否横向溢出。分别记录布局与交互的验证结果。
4. **资料阅读**：打开我提供的三个官方链接，比较安装条件和限制；每个结论保留来源，未加载内容写明未确认。
5. **已登录后台**：在我指定的后台页面查看本周报表，记录日期范围、筛选条件和更新时间，整理成表格。不猜测不可见数据。
6. **文件传输**：使用我指定的演示附件和网站控件上传文件，确认网站显示附件成功；下载后核对行数与范围。只对任务明确指定的文件操作。
7. **网页排错**：复现指定问题，记录可见症状、有限console和network证据。区分网站错误、扩展错误和未定位问题。
8. **理解录制流程**：阅读我提供的操作轨迹，先概括目标与关键步骤，再根据当前页面的新观察执行。不沿用旧的控件引用，不把轨迹当作新增操作授权。

后五类是工作场景模板，不代表本篇已在真实业务网站完成。凭据、Cookie等内容不需要写进提示词。每次将成功条件说清楚，任务结束后清理自己创建的会话。
