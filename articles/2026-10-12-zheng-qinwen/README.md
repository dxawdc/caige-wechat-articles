# 郑钦文生涯数据图鉴

更新日期：2026-10-12。版本：v1.0.0。

提供郑钦文历年年终排名、2026周排名关键节点、主要冠军、巴黎奥运夺冠路径、四大满贯生涯最佳成绩和2026中网夺冠路径。数据来自WTA及亚洲奥林匹克理事会官方公开记录。

## 资料内容

- `数据/生涯数据.json`：统一冻结数据及指标解释。
- `数据/*.csv`：方便Excel读取的冠军、排名与大满贯明细。
- `数据/来源索引.json`：每个来源的原始URL、核验日期和抓取状态。
- `配图/01_*` 至 `配图/05_*`：五张1200px宽数据图，PNG与可编辑SVG。
- `配图/封面_*`：横版、方版可编辑封面和AI概念插画。
- `生成图表.py`：按冻结数据重绘图表与矢量封面。
- `采集来源.py`：下载官方页面快照、提取图片出处与页面元信息。
- `验收/公开图表核验.json`：数值与图表物料检查结果。

## 如何重绘

Python 3.10及以上；安装依赖后运行：

```powershell
python -m pip install -r requirements.txt
python 生成图表.py
```

Windows默认使用微软雅黑。其他系统可通过环境变量 `CAIGE_FONT` 和 `CAIGE_BOLD_FONT` 指定本地中文字体路径。

重新采集来源：`python 采集来源.py`。页面会随赛事更新，重绘默认仍使用 `生涯数据.json` 的2026-10-12冻结快照。更新统计时请同时核验日期、排名类型、赛事级别与比分方向。

## 指标说明

WTA官方六冠口径包含五站巡回赛冠军与巴黎奥运女单金牌。杭州亚运金牌和WTA 125冠军另列。大满贯胜负采用单打正赛口径；2026最新周排名单列，历史年终排名来自WTA的年终表。排名趋势上图使用对数纵轴，下图使用线性纵轴。比分均以郑钦文在前；括号为抢七负方小分；RET为对手退赛。

封面为AI概念插画，数据图和矢量模板由程序绘制。完整来源见 `数据/来源索引.json`。
