# 有了AI，我怎么更忙了？

三页十八格职场漫画，按“没有 AI / 有了 AI”对照早起、工作、吃饭、下班和睡觉。提供 1024×1536 原图、分镜、生成提示词、横版与方版封面，以及可编辑 SVG 封面模板。

版本：v1.0.0，更新日期：2026-10-21。

## 阅读漫画

依次打开 `01_从起床开始.png`、`02_等一会到底是多久.png`、`03_下班了还没下线.png`。

故事来自作者给定的日常办公情境，以夸张方式呈现“AI 在干活，人还在不断派活”的反差。漫画由 AI 辅助绘制；界面、任务进度及额度重置情节为示意。

## 使用封面和分镜

- `分镜与制作说明.txt`：18 格的场景、台词及人物设定。
- `生成提示词.txt`：三页漫画的新画风提示词与局部修正指令。
- `配图/封面_横版.png`、`配图/封面_方版.png`：同画风封面成图。
- `配图/封面模板_横版.svg`、`配图/封面模板_方版.svg`：文字、色块、电脑和任务卡均可单独编辑的模板。
- `配图/封面模板_横版.png`、`配图/封面模板_方版.png`：模板导出预览。
- `封面生成提示词.txt`、`标题与封面说明.txt`：封面的生成方式、文案及设计依据。
- `物料清单.json`：每个公开文件的路径、大小和 SHA-256。

用 Inkscape 或支持 SVG 的编辑器修改标题与色块，可直接导出 PNG。运行下面的命令可以重新生成 SVG 模板，只需要 Python 3 标准库：

```sh
python 生成封面模板.py
```

AI 图像可参考所附提示词继续修改，以实际成图核对人物动作、屏幕朝向和中文文字。
