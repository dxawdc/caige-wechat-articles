## 本包解决什么问题

15 条登录日志 → 14 个用户日 → 连续段 → 历史窗口最长与截止日当前连续。

预期结果：**最长/当前：A=3/2、B=5/5、C=1/0、D=1/1；日期减序号与 LAG 两种算法一致。**
