# 2026 爱知·名古屋亚运会：公众号配套资料

对应公众号文章《今年亚运会好像没什么热度，只知道名古屋被骂上热搜》（数据截止 2026-09-22，赛事第 4 日）。

本文从亚奥理事会（OCA）官方成绩系统拉取第 20 届亚洲运动会的全量结构化数据，覆盖 46 个代表团、59 个比赛项目、12,753 名参赛选手、251 枚奖牌，以及全程 450 枚金牌的决赛日程与 28 条破纪录明细；用 11 张图拆开看：奖牌榜结构、各国优势项目分布、中国队金牌构成、选手画像、赛程节奏与投入产出效率。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `scripts/` | 采集、分析与绘图脚本（Python 3.10+）：`采集_官方成绩.py` 拉取全部接口，`采集_决赛日程与纪录.py` 拉取全程决赛日程与破纪录明细，`补全奖牌明细.py` 取全量明细并交叉核对，`分析.py` 生成八主题统计，`绘图.py` 输出 15 张中文图表 |
| `data/` | 官方数据快照：奖牌榜、251 条奖牌明细、多牌选手明细、12,781 条报名记录（精简 CSV）、代表团/项目/场馆/赛程矩阵，全程决赛日程与 28 条破纪录明细，以及分析产出的分主题 CSV 与 `统计结果.json` |
| `images/` | 15 张分析图表与公众号封面 |

## 数据来源与口径

- **数据源**：亚奥理事会（OCA）官方成绩系统 Bornan WebResults，接口前缀 `https://back.results.asiangames2026.org/s/AG2026/{lang}/`，赛事代码 `AG2026`，`{lang}` 支持 `en` / `zh`。
- **响应解码**：接口返回体存在 UTF-8 转义导致的畸形压缩流，需按 `utf-8 解码 → latin-1 回转 → zlib 解压` 处理（采集脚本内 `_inflate` 已封装）。
- **奖牌明细口径**：官方「逐日奖牌」接口当天数据存在滞后（实测少 1 枚金牌），因此明细统一改用「按代表团」接口 `medals/org/{Org}` 逐个拉取，251 条记录与官方奖牌榜 34 个代表团逐项核对，差异 0 条。
- **两套奖牌口径**：项次口径 = 251 条奖牌明细（团体项目记 1 条）；个人口径 = 430 位奖牌得主（团体成员逐个展开）。两者不能混用。
- **年龄样本**：251 条奖牌记录中 187 条含出生日期（团体、双打记录无个人生日），年龄相关结论基于该子集。
- **全程金牌日程**：`schedule/day/{YYYY-MM-DD}` 返回每日全部场次，每条带「是否金牌场次」标记，按天汇总即得当天预排金牌数；整届合计 450 枚。
- **破纪录明细**：`{项目代码}/records-v2/broken` 返回该项目的破纪录列表（选手、成绩、纪录级别）；同一次成绩可能同时刷新多个级别的纪录，故按「条」计数，共 28 条。

## 复现方式

1. 新建 Python 3.10+ 虚拟环境，安装依赖（`pandas`、`numpy`、`matplotlib`）。
2. 运行 `scripts/采集_官方成绩.py` 可重新拉取最新数据；赛事进行期间数据每日更新。
3. `scripts/分析.py` 生成八主题统计与分主题 CSV，`scripts/绘图.py` 输出 15 张图表。脚本按相对路径定位数据目录，把 `data/`、`images/` 与脚本的父目录平级放好即可运行。

数据为公开赛事成绩接口导出，供学习和研究使用。
