# 全国358家5A景区，哪里最多？门票多少钱，又靠什么赚钱？

数据核对日：2026-10-05。当前版本：v1.0.0。

全国358家主表、省级359条归属、市级362条归属；作者主体验分类；18家非随机票价核验样本；5家上市运营公司2023—2025年合并财务。

## 物料

- `data/`：CSV统计表、逐项来源与口径、地图边界、数据校验结果。
- `图集/`：8张3840×2160电脑端高清横图与总览。
- `文章配图/`：9张公众号阅读图和首尾品牌GIF。
- `scripts/`：两套统计图的绘图源码。
- `研究说明.txt`：定义、分母、样本范围与复算说明。

## 查看与下载

[独立ZIP](../../downloads/5a-scenic-analysis.zip)；查看[CSV主表](data/全国5A景区主表.csv)与[来源索引](data/来源索引.csv)。

## 复现

Python 3.10+；安装依赖后，在解压目录运行：

```bash
python -m pip install -r requirements.txt
python scripts/render_article_charts.py
python scripts/render_charts.py
```

源码在Windows使用微软雅黑。其他系统可在源码中指定已安装的中文字体；行政区图形使用Albers等积投影。绘图读取资料包内的核验快照，更新统计时应同时更新来源、主表及相关派生表。

## 数据来源与阅读方法

景区名称与简介：[文旅部数据服务](https://sjfw.mct.gov.cn/site/dataservice/base)。全国数量：[文旅部大众旅游服务](https://lyfw.mct.gov.cn/site/special/home)。

[最新19家正式认定公告](https://www.gov.cn/zhengce/zhengceku/202412/content_6995024.htm)；[2024年2月21家认定公告](https://zwgk.mct.gov.cn/zfxxgkml/zykf/202402/t20240206_951222.html)。

票价逐项来源在`门票核验样本.csv`，采用常规成人旺季基础票，包含项目范围见表。18家样本均价83.1元、中位数65元。报告2023年全国5A均价68元，两者时间与范围不同。

财务逐项来源和年报页码在`上市运营公司财务样本.csv`及`峨眉山收入构成.csv`。公司合并范围覆盖多个业务；图表用于理解运营公司收入结构。

省市统计按属地关系计数，全国去重按独立景区计数。四个直辖市整体统计；州、盟及省直辖县级单位按各自边界统计。类型为作者单标签研究分类。年度图为现存名录目录年回溯与有来源的历史节点。地图使用DataV边界用于统计示意，正式出版可选用审图认可底图。
