# WorkBuddy 提示词 100 例

版本 1.0.0 · 更新 2026-10-19 · 作者 才哥

使用方法：把【】里的内容换成自己的信息再发送；涉及重要文件先用副本试；定时任务类提示词粘贴到「定时任务」的提示词栏，执行时间在定时规则里设置。

## 一、写作与文案

写周报、写邮件、改稿子，关键是把读者和用途告诉它。

### 01｜零散记录整理成周报

```text
这是我这周的工作记录：【粘贴或上传】。请整理成周报，分「本周完成、遇到的问题、下周计划、需要的支持」四部分，每部分不超过5条，能用数字说明进展的就用数字，语气平实，不写空话。
```

### 02｜写一封工作邮件

```text
帮我写一封邮件给【对象和身份】，目的是【说明事情】，要点有【要点1、要点2、要点3】。开头一句说清来意，结尾写明希望对方在【日期】前回复什么。给我正式版和简短版两个版本。
```

### 03｜把专业内容改得更好懂

```text
下面这段话是写给【读者，比如：刚入职的新同事】看的，请改得更容易懂：长句拆短，术语第一次出现时用一句话解释，意思不能变。改完列出你改了哪些地方。【粘贴原文】
```

### 04｜先列方案提纲

```text
我要写一份【方案名称】，给【谁】看，目的是争取【预算、人手或支持】。先别写正文，帮我列提纲：每节用一句话说明要讲清什么、需要哪些数据支撑。我确认后再展开。
```

### 05｜整理会议纪要

```text
这是会议的录音转写或笔记：【上传文件】。整理成会议纪要：会议结论、待办事项（谁、做什么、截止时间）、还没定下来的问题。原文没提到负责人的待办标注「待确认」，不要自己编。
```

### 06｜学会我的写作习惯

```text
附件是我写过的3篇文章【上传】。请先总结我的写作习惯，包括开头方式、句子长短、常用词和排版，列成清单给我确认。确认后按这份清单写【新主题】的初稿。
```

### 07｜一次想10个标题

```text
这篇文章写给【读者】看，主要讲【核心内容】。帮我想10个标题，分成三类：直接说收益的、提出问题的、带数字的。每个标题后面注明对应正文哪部分内容，正文兑现不了的说法不要用。
```

### 08｜只校对，不改写

```text
帮我校对这份文稿【上传】：只找错别字、病句、标点、前后数字不一致、专有名词写法不统一的地方，用表格列出「原文、建议、原因」。不要改写我的观点和语气。
```

### 09｜一篇长文改成三种版本

```text
把这篇长文【上传】改成三个版本：朋友圈文案（100字以内）、小红书正文（300字左右，带3个话题标签）、给领导的口头汇报稿（1分钟能讲完）。
```

### 10｜写一份分享讲稿

```text
我要做一个【10】分钟的分享，主题是【主题】，听众是【听众】。帮我写讲稿，按说话的口吻写，每段标注大概讲多久，中间安排一个提问或小故事，结尾留一句好记的话。
```

## 二、Word、PPT 与 PDF

办公文件类任务，记得说清最后要什么格式、能不能继续编辑。

### 11｜按公司模板排 Word

```text
用附件里的公司模板【上传模板】，把这份草稿【上传草稿】排成正式文档：标题层级按模板来，表格统一样式，保留页眉页脚，最后输出可以继续编辑的 Word 文件。
```

### 12｜材料做成汇报 PPT

```text
根据这份材料【上传】做一份 PPT，给【听众】汇报，讲【10】分钟，大约【12】页。每页一个核心观点，页面标题直接写结论；数据尽量做成图表，文字和图表都要能继续编辑。先给我每页的大纲，确认后再做。
```

### 13｜提取 PDF 里的表格

```text
把这份 PDF【上传】里的表格全部提取出来，每张表放进 Excel 的一个工作表，工作表名称用 PDF 里的表标题，并注明来自第几页。识别不清的数字标黄。
```

### 14｜看懂一份合同

```text
帮我读一下这份合同【上传】，用表格列出：双方主要义务、付款方式和时间、违约责任、解约条件，以及对我方不利或表述含糊的条款，每条注明原文第几条。这是帮我理解用的，不作为法律意见。
```

### 15｜对比两个版本的文档

```text
对比这两个版本的文档【上传旧版和新版】，按章节列出所有新增、删除和修改，修改的地方写出「原来」和「现在」。最后用三句话总结主要变化。
```

### 16｜长报告做三层摘要

```text
这份报告【上传】太长了，帮我做三层摘要：一句话结论、300字左右的摘要、按章节的要点清单。重要数据后面标出页码，方便我回去核对。
```

### 17｜按名单批量生成文档

```text
附件 Excel 里有【30】位客户的信息【上传】，Word 模板里用【姓名】【金额】【日期】标出了要替换的位置【上传】。帮我每人生成一份文档，文件名用「姓名_通知」，放进一个新文件夹。先生成2份让我检查。
```

### 18｜只美化 PPT 样式

```text
这份 PPT【上传】内容不用改，帮我统一样式：字体、字号、配色一致，元素对齐，文字太多的页拆成两页或改成要点。改了哪些页，列个清单告诉我。
```

### 19｜扫描件转成可编辑文字

```text
这些是扫描的图片或 PDF【上传】，帮我识别成可以编辑的 Word，保留原来的段落和表格。人名、金额、日期这类容易认错的地方，单独列一张表让我核对。
```

### 20｜批量转换文件格式

```text
把【文件夹】里的 Word 文件全部转成 PDF，文件名不变，放进新建的「PDF版」文件夹。完成后告诉我一共转了几个、有没有失败的。
```

## 三、表格与数据分析

先体检、再分析；口径和规则提前说清，比事后返工省事。

### 21｜先给数据做个体检

```text
这是我的数据【上传 Excel 或 CSV】。先别分析，做一次体检：一共多少行多少列、每列是什么类型、空值和重复有多少、有没有明显异常的值。用表格告诉我，再建议怎么清洗。
```

### 22｜合并多张格式相近的表

```text
【文件夹】里有【12】个月的销售表，格式基本一样。帮我合并成一张总表，加一列「月份」。列名不一致的地方先列出来问我，不要自己猜。
```

### 23｜做一张能复用的汇总表

```text
用这份数据【上传】按【地区】和【产品】汇总销售额、订单数和平均客单价。计算的地方保留公式，下个月我换上新数据还能接着用。
```

### 24｜为一个观点选图

```text
我想说明【观点，比如：华东的增长主要来自新客户】，数据在附件里【上传】。帮我选最合适的图表并画出来，说明为什么选这种图，图表标题直接写结论。
```

### 25｜找出变化最大的地方

```text
这是最近两个月的数据【上传】。帮我找出变化最大的5个指标或分组，每个说明：变了多少、主要是哪部分带来的、可能的原因。原因只根据数据说，推测的内容要标明是推测。
```

### 26｜写一个 Excel 公式

```text
我想在 Excel 里做到：【描述需求，比如：根据 B 列入职日期计算工龄，满一年才算一年】。帮我写公式，解释每一部分的意思，再举两个例子验证结果对不对。
```

### 27｜按规则清洗表格

```text
帮我清洗这份表格【上传】：日期统一成 YYYY-MM-DD，手机号去掉空格和横线，删除完全重复的行，【城市】列统一写法（比如「北京市」统一为「北京」）。告诉我清洗前后各有多少行、改了哪些地方。
```

### 28｜固定报表写成脚本

```text
每周我都要用这份原始数据【上传】做一张同样的报表【上传样表】。帮我写一个 Python 脚本自动完成，以后我只要换原始文件再运行就行，附上运行说明。
```

### 29｜做一个本地数据看板

```text
用这份数据【上传】做一个本地就能打开的 HTML 数据看板：顶部放3到4个关键指标，下面放趋势图和分组对比图，可以按【月份或地区】筛选。
```

### 30｜分析问卷结果

```text
这是问卷结果【上传】。请帮我：①统计每道选择题的比例并出图；②把开放题的回答归成几类，每类举2条原话；③写一页总结，说明大家最满意和最不满意的地方。
```

## 四、文件整理

动文件之前先让它列方案，确认后再移动或改名，删除留给自己决定。

### 31｜整理下载文件夹

```text
帮我整理【下载】文件夹：先按类型和用途提出分类方案，列出每个文件准备移到哪里。我确认后再动手，不要删除任何文件。
```

### 32｜照片按日期改名

```text
把【文件夹】里的照片按拍摄日期重命名，格式是「2026-10-19_001.jpg」。先列出前10个文件的改名对照给我看，确认后再全部改。
```

### 33｜找出内容重复的文件

```text
帮我找出【文件夹】里内容重复的文件（不只是名字像），列出每组的路径、大小和修改时间，并标出建议保留哪一个。只列清单，不删除。
```

### 34｜整理一个月的发票

```text
【文件夹】里是我这个月的发票（PDF 和图片）。帮我识别每张的开票日期、销售方、金额和发票号码，汇总成 Excel，再把文件改名为「日期_销售方_金额」。识别不确定的单独标出来。
```

### 35｜项目结束后归档

```text
项目【名称】结束了，帮我把【文件夹】整理成归档结构：方案、过程文件、最终交付、参考资料四类，再写一份「归档说明.md」，说明每类里有什么、最终版是哪一个。
```

### 36｜看看什么最占空间

```text
帮我看看【目录】里哪些文件和文件夹最占空间，列出前20个，标出哪些像是安装包、缓存或重复备份。只列出来，删不删由我决定。
```

### 37｜桌面截图分类

```text
桌面上有很多截图，帮我按内容分类（聊天记录、报错信息、表格、网页等），分别移到对应文件夹，看不出内容的放进「待确认」。
```

### 38｜生成文件清单

```text
给【文件夹】生成一份文件清单 Excel：文件名、类型、大小、修改时间、所在子文件夹，按修改时间从新到旧排列。
```

### 39｜批量提取简历信息

```text
【文件夹】里有【20】份简历（PDF 和 Word）。帮我提取姓名、学历、工作年限、最近一家公司和主要技能，整理成 Excel，再按岗位要求【粘贴要求】给每份打匹配度，写明理由。
```

### 40｜看懂交接来的文件夹

```text
【文件夹】是同事交接给我的，我完全不了解。帮我把里面的文件过一遍，写一份说明：这些文件分别是做什么的、哪些最重要、建议我先看哪几个。
```

## 五、信息搜集与调研

让它联网查资料时，要求附上出处和日期，方便自己核对。

### 41｜一页行业简报

```text
帮我联网查一下【行业】最近半年的主要变化，整理成一页简报：关键事件（附日期和来源链接）、主要参与者、值得关注的趋势。只写能找到出处的信息。
```

### 42｜几款产品横向对比

```text
对比【产品A】【产品B】【产品C】的价格、核心功能、适合人群和优缺点，做成表格。价格和功能以官网为准，附上网址和查询日期。
```

### 43｜读懂一个网页

```text
帮我读一下这个网页【链接】：主要讲了什么、有哪些具体数据或结论、作者的依据是什么、哪些说法还需要再查证。
```

### 44｜多篇文章观点汇总

```text
这里有【5】篇讲同一个话题的文章【链接或文件】。帮我汇总：大家观点一致的地方、有分歧的地方、各自的依据。最后列出需要我自己判断的问题。
```

### 45｜从网页抓取列表数据

```text
打开【网址】，把列表里的名称、价格、评分和链接整理进 Excel，翻页抓取前【5】页。遇到需要登录或验证的页面就停下来告诉我。
```

### 46｜用大白话解读政策

```text
帮我找到【政策名称】的官方原文，用大白话解释：适用于谁、有哪些变化、从什么时候开始、对【我的情况】有什么影响。附上官方链接。
```

### 47｜找公开数据来源

```text
我想研究【问题】，需要哪些数据？帮我找可以公开获取的数据来源，列出名称、网址、数据范围、更新频率、是否免费，以及下载方法。
```

### 48｜整理一家公司的资料

```text
帮我整理【公司名】的基本资料：主营业务、近三年营收和利润、主要产品、最近的重要新闻。财务数据以年报或公告为准，注明来源。
```

### 49｜读一篇论文

```text
帮我读这篇论文【上传 PDF】：研究了什么问题、用了什么方法、主要结论是什么、局限在哪里。再用两三句话讲给不懂这个领域的人听。
```

### 50｜逐条核查一段内容

```text
下面这段内容里有不少数据和说法【粘贴】，帮我逐条核查：找得到出处的附上链接，找不到或说法有出入的标出来，并给出准确的说法。
```

## 六、学习与知识库

学东西时，让它出题、追问、引用原文，比只看总结记得牢。

### 51｜做一份学习计划

```text
我想在【8】周内学会【技能】，每天能投入【1】小时，现在的基础是【描述】。帮我做学习计划：每周目标、每天学什么、推荐资料、怎么检验自己学会了。
```

### 52｜检查我的理解

```text
我刚学了【概念】，下面是我的理解【写下来】。请像老师一样检查：哪里说对了、哪里有误解、漏了什么。然后出3道题考考我。
```

### 53｜只按资料库回答

```text
根据资料库里的【文档或文件夹】回答：【问题】。注明引用了哪份文档的哪一部分；资料里没有的内容直接说没有，不要自己补充。
```

### 54｜划线整理成读书笔记

```text
这是我的读书划线和笔记【上传或粘贴】。帮我整理成读书笔记：全书主线、我划线最多的几个主题、可以用到工作里的3个做法。
```

### 55｜课程录音整理成笔记

```text
这是一节课的录音转写或字幕【上传】，帮我整理成笔记：知识框架（用多级标题）、重要概念解释、老师举的例子、课后可以练习的问题。
```

### 56｜拆成知识卡片

```text
把这份资料【上传】拆成【20】张知识卡片，每张一个知识点，正面是问题、背面是简洁答案，导出成 Excel，方便我导入背诵软件。
```

### 57｜模拟面试

```text
我在准备【岗位】的面试。请扮演面试官，每次只问一个问题，等我回答后点评打分，再问下一个。一共10题，最后给我总体建议。
```

### 58｜翻译顺便学表达

```text
把这段中文【粘贴】翻译成英文，用在【场景，比如：给海外客户的邮件】。然后挑出5个值得我学的表达，说明用法。
```

### 59｜辅导孩子做题

```text
孩子读【年级】，这道题不会【上传题目图片】。先不要给答案，写一份我可以用来引导孩子的思路：先问什么、怎么提示，最后再给完整解法。
```

### 60｜整理成个人知识库

```text
帮我把【文件夹】里的学习资料整理进资料库：按主题分类，每份资料写一句摘要，再生成一份总目录。以后我提问时优先从这里找答案。
```

## 七、自媒体与创意设计

做图前先让它说方案，确认后再生成；图里的中文要逐字检查。

### 61｜找10个选题

```text
我的账号写【领域】，读者主要是【人群】。帮我联网看看最近一周这个领域大家在讨论什么，给我10个选题，每个写清：读者为什么会点开、我能用什么内容兑现。
```

### 62｜做一张公众号封面

```text
给这篇文章【上传】做一张公众号封面，横版 2.35:1。主文案不超过两行：【文案】。风格【描述】，不放复杂图表，缩到手机列表大小时文字也要看得清。
```

### 63｜长文改成小红书图文

```text
把这篇文章【上传】改成一组小红书图文。先列出准备做几张、每张讲什么，我确认后再做图。第一张要能一眼看出主题，每张的字不要太多。
```

### 64｜写短视频脚本

```text
帮我写一个【60】秒的短视频脚本，主题是【主题】。用表格写：时间段、画面、台词、字幕。前3秒要有一个让人停下来的问题。
```

### 65｜商品图换白底

```text
把这几张商品图【上传】的背景去掉，换成纯白底，尺寸统一成 800×800，文件名不变，另存到新文件夹。
```

### 66｜整理读者留言

```text
这是最近的读者留言【粘贴】。帮我分成提问、建议、夸奖、吐槽四类；提问类起草回复，语气友好，不确定的问题标出来，我自己回。
```

### 67｜复盘账号数据


## 八、定时任务

早报、周报、价格记录这类固定的事，设置一次，到点自动跑。

### 71｜每日行业早报（工作日 8:30）

```text
联网搜集过去24小时【领域】的重要新闻，挑出5条，每条写标题、一句话摘要和来源链接，按重要程度排序，整理成一份简报。
```

### 72｜周报草稿（每周五 17:00）

```text
读取【工作空间】里本周修改过的文件和【工作记录文件】，整理成周报草稿：完成事项、遇到的问题、下周计划，保存为「周报_日期.docx」。
```

### 73｜A 股收盘速览（工作日 15:30）

```text
联网查询今天上证指数、深证成指、创业板指的收盘点位和涨跌幅，以及涨幅前5和跌幅前5的行业，整理成一张表加三句话总结，数据注明来源。
```

### 74｜商品价格记录（每天 10:00）

```text
打开【商品链接】，把当前价格和日期追加到【价格记录.xlsx】。如果比上一次记录低了【5%】以上，在结果第一行提醒我。
```

### 75｜竞品动态（每周一 9:00）

```text
查看【竞品A、竞品B】的官网、更新日志和官方公众号，汇总上周的新功能和价格变化，没有变化的写「无变化」，附上来源链接。
```

### 76｜下载文件夹整理（每周日 21:00）

```text
检查【下载】文件夹，把30天以上没有修改过的文件按类型移到「待清理」文件夹，生成一份移动清单。不删除任何文件。
```

### 77｜每日单词（每天 7:30）

```text
从【单词表.xlsx】里按顺序取今天的10个单词，给出音标、释义和一个例句，并附上前一天10个单词的复习小测。
```

### 78｜今日待办提醒（工作日 8:45）

```text

```

### 79｜开源项目周榜（每周三 20:00）

```text
查看 GitHub 上最近一周星标增长最多的【AI 相关】开源项目，列出前10个：项目名称、用途、星标数和链接。
```

### 80｜月报（每月 1 日 9:00）


## 九、生活与个人事务

生活里的琐事也能交给它；涉及健康和办事，以官方和专业意见为准。

## 十、用好 WorkBuddy 本身

让它先出计划、反问、自查，再把好用的做法沉淀成技能。

### 91｜先出计划再动手

```text
这个任务比较复杂：【描述】。先别动手，给我一份执行计划：分几步、每步做什么、会改动哪些文件、哪些地方需要我确认。我说可以了再开始。
```

### 92｜让它先问我问题

```text
我想做【事情】，但自己还没完全想清楚。请先问我5个最关键的问题，等我回答后再开始做。
```

### 93｜帮我找合适的技能

```text
我经常需要【做某件事】。帮我看看已安装的技能里有没有合适的；没有的话去技能市场找2到3个，比较各自适合什么。安装前先告诉我来源和需要的权限。
```

### 94｜把好做法存成技能

```text
刚才这个任务的做法我很满意。帮我把它整理成一个技能，写清适用场景、步骤、输出格式和注意事项。以后我说「【触发说法】」，就按这个做。
```

### 95｜让它检查自己的结果

```text
检查一下你刚才的结果：数字和原始数据对得上吗？有没有漏掉的文件？哪些内容是推测而不是确认过的？列出问题并修正。
```

### 96｜告诉它我的偏好

```text
请记住我的偏好：【比如：文档用微软雅黑，表格数字保留两位小数，周报不超过一页】。以后的任务默认按这些来。
```

### 97｜只问不做，少花积分

```text
这个问题只需要你回答，不用读写任何文件：【问题】。回答控制在300字以内。
```

### 98｜接着中断的任务做

```text
刚才的任务中断了。先检查已经完成了哪些步骤、生成了哪些文件，从没完成的那一步接着做，不要从头再来。
```

### 99｜请专家审一遍

```text
请以【资深数据分析师】的身份审一下这份报告【上传】：从结论有没有依据、图表是否合适、表述是否清楚三方面提意见，按重要程度排序。
```

### 100｜复盘我的提示词

```text
回看我们这次对话：我最开始的需求哪里没说清楚，让你多走了弯路？下次遇到同类任务，我该怎么说？给我一个改进后的提示词模板。
```
