# WorkBuddy 提示词 100 例

写作、办公文件、表格数据、文件整理、信息调研、学习、自媒体创作、定时任务、生活事务，以及用好 WorkBuddy 本身，10 类共 100 条可以直接复制的提示词。

## 提供的物料

配套资料文件夹里是三种格式的完整清单：

- WorkBuddy提示词100例.html：可搜索、按分类筛选、一键复制的网页，双击即可在浏览器打开，【】会高亮显示。
- WorkBuddy提示词100例.xlsx：编号、分类、用途、提示词四列，方便筛选和二次整理。
- WorkBuddy提示词100例.md：Markdown 版清单，每条提示词放在独立代码块里，便于复制。

其他文件：

- 提示词库.json：100 条提示词的数据源，以上三种格式都由它生成。
- 4 张示意图（分类导航、四要素、定时任务写法、使用路径）与横版、方版封面：PNG 阅读版和可编辑 SVG。
- 生成配套资料.py、生成配图.py：重新生成清单与配图的源码；网页模板.html 是网页版的模板。

## 怎么用

把【】里的内容换成自己的信息再发给 WorkBuddy。会改动文件的任务，先让它列方案、确认后再动手；重要文件先用副本试。定时任务类提示词粘贴到「定时任务」的提示词栏，执行时间在定时规则里设置。

## 重新生成

使用 Python 3，依赖 openpyxl 和 Pillow。修改 提示词库.json 后运行：

```shell
python -m pip install -r requirements.txt
python 生成配套资料.py
python 生成配图.py --font "C:/Windows/Fonts/msyh.ttc"
```

其他系统通过 --font 指定已安装的中文字体。
