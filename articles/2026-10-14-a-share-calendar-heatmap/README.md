# A股日历热力图：这个夏天与近10年

更新日期：2026-10-14。版本：v1.0.0。

用日历热力图、跌幅排行和走势动图，对比2026年7月以来A股主要指数、韩国KOSPI与美股的表现，并把上证指数近10年（2017年1月至今）的每个交易日画成一面日历墙。

## 资料内容

- `数据/指数日线.json`：12个指数的日收盘价，含来源、代码与截止日。
- `采集数据.py`：从腾讯行情（A股指数）和Yahoo Finance（KOSPI、标普500、纳斯达克综合）采集日收盘。
- `绘图.py`：生成全部图表、动图和 `分析结果.json`。
- `分析结果.json`：文中引用的区间涨跌、跌超3%天数、年度涨跌和近10年统计。
- `图表/`：7张PNG图表、2张GIF动图（海内外走势、近10年日历墙）。
- `生成封面.py` 与 `配图/封面_*`：AI插画横版封面，以及可编辑的横版、方版SVG模板。

## 如何重绘

Python 3.10及以上：

```powershell
python -m pip install -r requirements.txt
python 绘图.py
```

`绘图.py` 直接读取 `数据/指数日线.json` 的2026-10-14快照。要更新到最新交易日，先修改 `采集数据.py` 中的 `CUTOFF` 与美股截止日，再依次运行 `python 采集数据.py` 和 `python 绘图.py`。Windows默认使用微软雅黑。

## 口径说明

- 均为本币价格指数，不含分红，不做汇率换算。
- A股指数截至2026-10-14收盘；KOSPI截至10-14收盘；美股截至10-13收盘。
- "7月以来"以2026-06-30收盘为基准；近10年累计以2016年最后一个交易日收盘为基准；年度涨跌以上一年末收盘为基准，2026年为年初至今。
- 日历图色阶：单日涨跌幅±3%封顶，红涨绿跌；空白为周末与节假日。
