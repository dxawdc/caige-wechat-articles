# 验收与故障定位

## 新站最小闭环

1. 无登录访问主页、搜索、分类和详情；检查手机及桌面布局、加载失败提示和控制台。
2. 真实数据库中存在已发布/未发布测试记录。匿名列表与详情都不能泄露未发布内容或内部字段。
3. 匿名调用所有写接口返回拒绝；普通已登录用户同样无管理权限。直接调用 Data API 的访问权限也需匹配。
4. 指定管理员可以新增、编辑和隐藏自己的测试内容。数据库值与界面一致；记录变更在缓存约定时间内反映前台。
5. 上传公开测试图片，重新加载仍可显示；匿名与普通账号不能上传、覆盖、删除。私有桶对象不能通过公开路径读取。
6. 用同名/同时间记录验证跨页顺序，不重复不遗漏；参数超限、非法字段和无效请求被合理处理。
7. 退出登录后不能继续在 UI 执行管理操作；过期或无效会话的服务端请求被拒绝。按选定会话模型说明 token 的撤销窗口，不承诺即时撤销而未实现。
8. 新部署或重启后内容依然保留。页面不把 mock 成功、localStorage 保存或文件系统临时写入当作数据库持久化。
9. 在构建产物和待提交内容中检查机密；只输出问题位置和配置名，不输出匹配到的密钥值。
10. 公网验证真实目标地址，记录提交和部署版本；HTTPS、静态资源、真实数据请求均通过才称上线成功。

已有站点仅做本次修改相关的比例验证；不要借验收批量改变生产数据。测试记录必须可识别，清理只针对本次创建且授权删除的记录。

## 常见现象

| 现象 | 先检查 | 后续处理 |
| --- | --- | --- |
| 本地有数据，线上为空 | 生产环境变量、Supabase 项目、是否演示模式 | 确认配置并重新部署；检查接口真实错误 |
| SQL 已建表，Data API 读不到 | schema 暴露、GRANT、RLS、查询字段 | 按实际访问模型补最小权限 |
| 能登录，无法保存 | 是否管理员、token 校验、策略与字段约束 | 区分认证和授权，不直接放开权限 |
| 保存成功，前台旧数据 | 数据库值、接口缓存、浏览器缓存 | 按设计失效/等待，避免重复导入 |
| 图片 403/404 | 桶名、对象路径、公开/私有、签名过期 | 修正访问方式与权限 |
| 接口返回 200 但页面报错 | content-type、响应是否 HTML | 修正重写与函数路由 |
| 域名打不开 | NS、当前权威 DNS、Vercel 域名验证、TLS | 默认域名成功后逐层检查，不反复换项目 |
| 免费项目暂停 | 平台状态与用量 | 正常恢复或评估升级，不伪造流量规避政策 |

## 完成记录

用短表分别写本地项目、构建/测试、真实数据库、Git 提交、远程分支、Vercel 部署、默认域名、自定义域名。每项标明已验证/待配置及必要证据；未测试部分不能因另一项通过而写通过。
