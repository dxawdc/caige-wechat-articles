# 免费起步的数据网站与 AI 建站 Skill

版本：1.0.0。整理日期：2026-10-10。

这套资料帮助你向 AI 描述一个带数据、管理后台的个人网站，使用 GitHub 管理代码、Vercel 托管页面和接口、Supabase 保存数据与图片，并按需要接入 Cloudflare DNS。

## 文件清单

- `build-free-data-website/`：可安装的技能，包含主流程、平台参考和验收规则。
- `需求模板.md`：可复制给 AI 的建站需求，以及分阶段追问示例。
- `上线验收表.md`：按游客、管理员、数据、部署和域名逐项检查。
- `demo-data.csv`：3 条人工编写的演示记录，可用 Excel 查看。

## 使用方法

1. 下载仓库 ZIP，打开 `articles/2026-10-10-free-data-website/`。
2. 将 `build-free-data-website` 整个目录交给支持技能的 AI 编程工具安装；重开会话确认该技能可用。具体技能目录按你所用工具的说明设置。
3. 也可以让有文件读取能力的 AI 先读取 `build-free-data-website/SKILL.md`，再读取按阶段引用的参考文件。
4. 在空项目目录中提交 `需求模板.md` 里的需求，让 AI 创建实际文件并启动本地预览。
5. 按生成项目的 README 完成数据库、管理员及环境变量配置，用验收表验证，之后在授权范围内推送和部署。

技能由 Markdown 和 YAML 组成。实际网站的运行依赖由 AI 根据所选框架生成，并写入项目的依赖锁文件和 README；账号注册、登录验证和域名购买由使用者完成。

## 演示数据

CSV 为人工教学示例，字段是 `name,category,description,image_path,is_published`。共 3 条，其中 2 条已发布、1 条草稿，用于验证公开访问是否正确过滤。图片路径留空，由应用显示占位图，上传后保存真实路径。创建时间和主键由数据库生成。

## 适用范围与费用

适合个人资料库、图鉴、作品站、工具导航等小型项目，先验证完整功能闭环，再按用量扩展。Vercel Hobby 的个人非商业用途要求、Supabase 免费额度、Cloudflare 的具体产品能力，以当前官方说明为准。独立域名与 AI 工具费用另计。

官方核对入口与权限说明见技能的 `references/platforms.md`。技能应由能实际读写文件、运行命令的编程工具执行；对话工具也可以据此指导人工操作。
