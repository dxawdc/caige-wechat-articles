# 数据字典

所有用户表每行一个独立模拟用户。user_id仅作追踪，不进入模型。RFM用户与流失、消费数据中的同名ID没有跨表关联含义。

| 数据文件 | 字段 | 定义/单位 |
| --- | --- | --- |
| spend | spend_30d | 观察截止前30天累计消费，元 |
| spend | orders_30d | 前30天下单次数，次 |
| spend | active_days_30d | 前30天有活动的天数，1—30天；样本为至少购买一次的用户 |
| spend | spend_next30d | 截止之后30天累计消费，元；回归目标 |
| churn | days_since_visit | 截止时距上次访问天数，0—29天，且小于注册时长 |
| churn | sessions_30d | 前30天访问次数，次 |
| churn | tickets_30d | 前30天工单次数，次 |
| churn | tenure_days | 截止时注册时长，天 |
| churn | churn_next14d | 未来14天无访问=1，否则=0；分类目标 |
| rfm | recency_days | 截止时距最近购买天数，越小越近期 |
| rfm | frequency_90d | 前90天下单次数，次 |
| rfm | monetary_90d | 前90天累计消费，元 |
| baskets | basket_id | 交易ID，不进入模型 |
| baskets | 八个中文商品列 | 当前订单是否含该商品，True/False；数量不计入 |

模拟特征在用户层按分布构造，不是一套完整事件账本。消费样本限定为前30天有购买的用户，流失样本限定为前30天有访问的用户；均约束次数至少1，访问距今天数小于注册时长。RFM限定前90天有购买，最近购买距今不超过89天。生产应用必须由同一事件口径汇总特征，而不是直接复用生成分布。

RFM也按教学分布生成，未包括退货、币种、负金额、新注册不足90天等业务处理。模拟公式详见make_data脚本；勿用其隐含概率或人群标签代替真实数据验证。
